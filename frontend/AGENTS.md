# 前端会话工作边界

本目录的会话只负责 VoiceTransl 前端实现与前端测试，工作范围为 `frontend/`。遵循仓库根目录 `AGENTS.md` 的产品、交互、安全和 Git 规则。

- 不修改 `backend/` 的代码或测试，也不替后端会话实现 API 或 Provider。
- 如需后端配合（例如缺少 API、字段、错误语义、运行时能力或状态契约），向后端开发会话发送明确请求，写明预期行为、方法/路径、请求响应字段和验收条件，请后端会话完成其范围内的实现。
- 后端尚未提供的能力不得在前端中假设为可用；应清晰禁用或提示，并与后端会话确认契约后再接通。
- 只读查看后端以了解现有 API 是允许的；不得把只读检查变成跨目录改动。
- 前端测试与构建命令见根目录 `AGENTS.md`。
