# VoiceTransl 前端工作流

本文维护当前 WebUI 的交互约定，替代旧 v0.2 前端设计。资源与 API 以[多音频项目契约](voicetransl_multi_audio_project.md)为准，架构见[架构约定](architecture.md)，进度与后续方向见[线路图](roadmap.md)。

## 1. 主流程与操作范围

项目列表 → 新建项目/添加音频 → 上传 → 选择音频 → 配置阶段 → 应用配置 → 启动独立任务 → 查看结果。

- 一个项目组织多个音频；上传不会自动开始 Pipeline，共享配置不会合并源文件、时间轴或字幕。
- **焦点音频**决定当前显示的任务、配置和结果；**勾选范围**决定批量应用配置及启动对象，两者必须分开。
- 界面明确展示操作对象和数量，未选音频不变。项目列表展示状态汇总，不能把单个音频的进度当成全项目进度。
- 旧项目仍可作为含主音频 `aud_primary` 的项目打开，不自动合并历史独立项目。
- 项目列表使用服务端分页与总数，默认每页 20 项；翻页隔离过期响应，创建/删除后保持有效页及页容量，删除后补页或退回有效末页，不把当前页当作完整项目集合。

## 2. 上传与重试

- 支持单文件、多文件选择和拖放；项目名只填一次，音频保留各自原始文件名。新建项目必须显式选择或输入源语言、目标语言，不能相同；支持 `zh-CN` 等非预设语言代码。追加音频仅要求源语言，目标继承现有项目。
- 从后端 `upload-policy` 获取扩展名和大小限制；规则加载失败可重试，取得前不提交。不要额外宣称完成 MIME 或真实音频内容校验。
- 同一文件重复选择时提示并跳过；不同的同名文件可以作为独立资源保存，不覆盖。
- 首个成功上传创建父项目，后续文件加入该项目；显示逐文件状态与数量，失败项在同项目独立重试，不重复创建成功资源。
- 上传期间锁定队列和基础信息，阻止应用内离开并提供浏览器离开提示。每项保存提交时的语言/命名快照，失败重试不能使用后来修改的表单值。队列仅保留于页面会话，刷新后通过项目/音频列表访问已保存资源。

## 3. 阶段配置与启动

- 五阶段节点只切换下方的阶段工作区，不直接打开弹窗；通过独立“配置此阶段”按钮编辑，不另设重复节点总览。
- 弹窗支持保存、取消及未保存修改提示；配置尚未加载时不能编辑。运行、取消中或已提交排队的音频只读，但允许查看配置和结果。
- 区分“本次任务快照”和“下次处理配置”，无快照时标记尚未开始，不把草稿模型展示为实际使用模型。
- 翻译模型可选字段用 JSON `additional_parameters` 配置，默认 `{}` 不发送可选字段；非法 JSON 阻止保存。导出可设置安全命名模板，结果依赖后端结构化元数据而非猜测文件名。
- 参数校验失败时定位到对应字段/阶段，不发起启动。编辑/应用配置与启动是不同动作：按新配置运行时须先成功保存，不能以保存失败前的旧配置意外启动。
- “应用到所选音频”逐项保存配置并展示成功/失败；“开始所选音频”使用各自保存的配置创建独立任务。批量开始不代表自动把焦点音频配置复制给所有音频。
- 失败、取消、中断任务的“继续”使用原任务快照；“重新处理”使用当前配置并创建新 Job ID。单项失败不取消其他音频，批量结果逐项显示，不重复启动已成功项。

## 4. 真实结果与状态展示

- 工作区按当前音频、当前 Job 和所选阶段读取详情；快速切换或重新处理后，旧请求响应不能覆盖新视图。
- 预处理展示音频资料及实际元数据，不伪造波形；ASR、对齐、翻译分别展示各自阶段的原始识别、对齐和翻译产物。
- 导出文件下载入口只放在导出工作区，不用最终译文替代 ASR 原文，不把旧任务产物冒充本次结果。
- 明确区分加载、未完成、跳过、失败及产物缺失；缺失时提供刷新/重新处理方向，不静默回退到其他阶段结果。
- 配置校验状态、上传状态与 Job 执行状态分开。WebSocket 用于实时通知，连接或重连后通过 REST 恢复真实状态，不轮询全部阶段。

## 5. 设置与安全操作

- 顶部“设置”在项目列表、上传页、工作区均可访问；打开/关闭不清空当前视图、队列或 WebSocket 连接。
- 本地 ASR 设置中的“检查”只检查草稿，不保存；保存显示重启生效提示，环境变量控制字段只读，版本冲突不得覆盖新配置。
- 模态框处理未保存关闭提示、键盘焦点约束和关闭后的焦点恢复。设置失败不取消任务。
- 本地模型仅在用户显式选择时更新草稿，不自动保存或修改语言；发现可选不等于推理就绪。完整规则见专题文档，不在此重复参数。
- 删除项目必须二次确认，说明会删除全部音频及字幕/输出；任何音频忙碌时禁止删除。
- API Key 只能由后端读取环境变量，前端仅处理变量名称。Profile 后端 API 不代表已有可用的云端 ASR；云端 UI 属于后续工作，不能提前宣称支持。
- 错误提示说明原因和下一步动作；上传/启动失败可逐项重试，运行失败定位阶段，连接失败提示检查服务，不只显示原始 500 文本。

## 6. 关键回归检查

1. 多文件只创建一个父项目；失败项重试不复制成功资源，未选音频配置和任务不变。
2. 节点查看与配置入口分开；保存/取消、未保存提示、忙碌只读正常。
3. 恢复旧快照与按新配置重跑语义不同；批量配置失败不会误用旧配置启动。
4. 切换音频、阶段或重新处理时，结果不串线，过期响应不覆盖当前视图。
5. 设置操作保留会话状态；删除确认及忙碌保护有效；Mock 流程不依赖真实模型或外部 API。

## 7. 节点工作流（首版）

项目工作区选择一个焦点音频 → 切换节点工作流 → 添加/配置预处理、ASR 和输出节点及连线 → 校验并保存 → 运行节点工作流 → 查看运行记录/下载输出。

- 节点目录由 `/api/v1/capabilities` 提供，前端从目录读取类型、端口、默认配置和字段约束；未知节点通过通用字段编辑器接入，不复制永久类型/后端白名单。目录版本或结构无效时明确提示并允许重试，不用静态列表冒充成功。本地 ASR 发现失败不应阻止 Mock 或音频直通。当前画布每侧仅支持一个端口，多端口定义明确拒绝，不宣称通用汇合已经实现。
- 这是与旧五阶段独立的模式，支持音频输入、Mock/FFmpeg 预处理、Mock/CrispASR 识别及音频/文本输出；旧阶段配置、运行和结果继续保留，不自动转换为节点图。图模式隐藏旧 Pipeline 启停按钮，避免控制错任务。
- 图定义按项目保存，运行只针对当前焦点音频，不使用旧界面的批量勾选范围。输入绑定该音频；可增删预处理/输出节点、连接/断开、拖动、缩放/平移和适配画布。输出独立配置文件名主体；预处理独立配置 Provider、采样率和声道，明确源文件始终保留。
- 输入与预处理节点提供音频输出端口，预处理、ASR 与音频输出节点接受一个音频输入；ASR 提供识别结果端口，文本输出接受一个识别结果输入。可串联处理或保留原音频直出分支。新增节点不会自动改接已有输出，需显式建立连线；类型不匹配、非法方向和循环连接被拒绝。
- Mock 仅复制上游字节来验证链路，不实际转换采样率或声道；真实转换选择 FFmpeg，服务端缺失或转换失败会显示错误，不自动回退到 Mock。
- ASR 每节点独立设置 Provider、识别语言、模型/后端、VAD 和分段时长。Mock 仅返回演示文本；CrispASR 模型选择复用现有本地模型发现，不自动选择或下载。实际输入必须为 16 kHz 单声道 PCM WAV，不合格时提示调整 FFmpeg；满足格式的源文件可以不经过预处理。
- 文本输出每节点选择 TXT/SRT/VTT/LRC 和安全文件名主体，多个节点可同时导出不同格式；导出 ASR 原文而非译文。TXT 可输出无时间戳的原文，字幕输出缺少有效时间范围时失败，不伪造时间戳。图只含文本输出也可运行。
- 未保存的草稿不能运行；无效图不能保存，校验和版本冲突失败保留草稿。切换模式、音频或返回项目列表时，未保存修改需确认放弃。
- 活动运行时图只读，并阻止应用内离开或切换历史；状态通过 REST 轮询，保存/校验和过期请求不能覆盖新运行或新视图。刷新后可重新查询该音频历史。
- 历史区区分运行快照和当前草稿，不把不匹配的历史状态标到已修改的节点上；预处理、ASR JSON 和输出产物按所选运行/节点真实下载，输入节点没有下载产物。下载可用性需经产物接口确认：区分检查中、文件缺失、检查失败与可下载；失败可重试，不拿历史快照里的地址冒充文件仍存在。
- 运行结束后可修改并保存图，再创建新运行，旧记录与文件保留。首版不提供从任意节点继续/强制重跑，也没有历史清理按钮。

回归检查覆盖配置校验、直出/处理混合分支、串联处理、失败与依赖阻塞、预处理产物下载，以及节点不重叠、移动端适配、保存与轮询并发、脏草稿导航提示、历史快照隔离，以及新旧模式互斥运行。后端范围与持久化见[架构约定](architecture.md#7-节点工作流首版)。

Provider 配置细节见 [CrispASR](crispasr_provider.md)、[全局本地 ASR 设置](voicetransl_global_settings.md)、[HTTP 翻译](translation_providers.md)及 [Provider Profile](provider_profiles.md)。测试和构建命令见 [AGENTS.md](../AGENTS.md)。
