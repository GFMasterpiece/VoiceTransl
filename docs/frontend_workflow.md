# VoiceTransl 前端工作流

本文描述当前 WebUI。资源/API 见[多音频项目契约](voicetransl_multi_audio_project.md)，执行与存储见[架构约定](architecture.md)，计划见[线路图](roadmap.md)。

## 主流程

项目列表 → 创建空项目 → 在音频输入节点上传或选择资源 → 编辑节点图 → 校验并保存 → 运行 → 查看预览、运行历史与产物。

- 项目列表使用服务端分页，默认每页 20 项；创建/删除后刷新有效页。分页请求按代次隔离，过期响应不能覆盖当前列表。
- 新建项目填写名称及语言后即可进入默认节点图，尚无音频时也能编辑、保存图；没有可用输入时不能运行。原多文件上传创建保留为批量导入次入口，一组文件归入同一项目，逐音频保存资源。
- 新运行由输入节点显式绑定的音频决定；历史音频选择器独立控制查看上下文，切换保留草稿和绑定。旧 `{}` 输入使用所选音频上下文。不同音频的时间轴、历史及产物不合并。
- 新建项目显式提供源语言、目标语言，两者不能相同；允许输入非预设语言代码。当前直通不进行语言处理，保留该项目元数据供后续功能使用。
- 创建不再发送或展示 `preset`。旧项目保留该字段不等于仍能切换旧处理预设。
- 当前只运行焦点音频，没有旧五阶段工作区、批量阶段配置/运行或恢复按钮。

## 界面语言

- 顶栏支持简体中文与 English，上传或节点运行期间也可以切换；界面文本、无障碍标签、确认弹窗、状态及已知错误提示随之更新，日期和数字按当前语言格式化。
- 首次打开按浏览器语言列表选择第一个支持的语言，均不匹配时使用简体中文；之后优先使用本机浏览器保存的选择。偏好保存在 `localStorage` 的 `voicetransl.locale`，不写入项目。浏览器禁止存储时仍可在当前页面切换。
- 切换语言不重新加载工作区，不清空表单、上传队列或未保存节点图，不改变文件、当前音频、运行记录及提交快照。界面语言与项目的源语言、目标语言、Mock ASR 的结果语言相互独立。
- 内置节点和已知错误码有对应译文。节点类型、端口、配置键和选项值继续使用原协议标识；未知扩展的节点、字段、选项和错误诊断保留服务端原文，不阻止其按能力目录接入。用户填写的项目名、文件名和节点配置不翻译。
- 消息集中在 `frontend/src/i18n/messages/`，分为 `common`、`app`、`workflow`。新增文案须同步两种语言的键和插值参数；扩展语言时同步语言注册、检测、选择入口及测试，不在组件中另建文案名单或以译文判断业务逻辑。

## 上传与重试

- 支持单文件、多文件和拖放；项目名称只填一次，每条音频保留原始文件名。
- 上传扩展名与大小限制来自 `upload-policy`，加载失败可重试，成功前不提交。该规则不等于 MIME 或音频内容解码校验。
- 批量导入时首个成功文件创建父项目，后续文件追加；同一文件重复选择被提示跳过，不同同名文件可独立保存。
- 音频输入节点中可选择项目已有音频、选择新文件或拖放单个文件；源语言明确显示且可编辑。节点上传直接向已有项目追加资源，显示上传中状态，失败保留文件可重试；上传成功后绑定新资源并标记图草稿，仍需保存才可运行。上传中锁定编辑和导航，浏览器离开也有保护；不伪造上传百分比。
- 失败项在原项目单独重试，不复制成功资源。每项保留提交时的语言/命名快照，重试不套用后来修改的表单。
- 上传期间锁定表单与队列，阻止应用内离开并提供浏览器离开提示；刷新后从项目中访问已保存文件，不恢复内存队列。

## 节点图

- 默认只有 `audio_input -> audio_output`，两端使用 `audio` 端口，不要求加入处理节点。
- 可添加音频预览、文本预览节点作为分支终点。音频输入可直连音频预览；Mock ASR 的转写可连接文本预览。只有预览、没有导出节点的图也可保存运行。音频输入负责上传和资源绑定，不内置预览播放器。
- 可选 Mock 预处理仅复制原字节；Mock ASR 生成固定示例文本，`language` 只标注结果语言。它们不是实际预处理/识别能力。
- Mock 预处理只保留 `provider=mock`；Mock ASR 只保留 `provider=mock` 和 `language`。不显示模型、后端、VAD、分段、Profile、采样率、声道或源文件删除设置。
- 音频输出配置安全文件名；文本输出配置安全文件名和 TXT/SRT/VTT/LRC 格式，用于导出 Mock 结果。没有翻译、对齐或视频节点。
- 节点类型、端口目录、数据类型目录、源节点标记、字段约束、图限制及新建时的默认图来自 `/capabilities` 的 `workflow` capability schema `1.3`；端口以 `{id, type_id, label, capability_requirements}` 发布，节点和边只使用稳定的端口 `id`，展示名称与逻辑类型由目录提供。节点可空的 `presentation` 声明资源控件及预览渲染器，前端按元数据选择组件。前端只根据目录镜像父类型和能力要求做即时连接提示，不复制后端执行逻辑，也不重复维护格式白名单、默认配置或节点/边数量规则。旧 capability schema `1.0/1.1/1.2` 明确报版本不兼容，不用旧格式或静态默认值降级。目录无效/读取失败明确报错并允许重试；客户端校验只作即时提示，后端验证为最终权威。此 capability version 不同于持久化工作流 schema version `1.0`。
- 支持节点添加/删除、拖动布局、拖拽连线/断开及缩放平移。可以从源输出端口拖到目标输入端口，也可以从目标输入端口拖到上游输出端口；保存的边始终为输出到输入，拖动方向不改变数据处理方向。释放到空白处、画布外或同方向端口时取消待连接状态。端口拖拽不会触发节点移动，也不会提前断开已有连线；只有合法新连接完成时才替换目标原有入边。新增节点不暗中替换原有连线；连线由后端根据源端口和目标端口绑定的逻辑 `type_id` 判断兼容，不能仅比较端口名称。具体音频实现可以通过父类型或能力契约满足 `audio`，因此不要求所有音频对象使用同一个 Python 类。当前后端注册契约与画布均限制每个节点至多一个输入端口和一个输出端口，升级为多端口前须同步扩展后端节点注册/校验与画布连接点。
- 网格平铺覆盖整个可视画布，随节点图同步平移、缩放，容器变宽或变高后自动覆盖新增区域；低倍缩放使用更疏的网格，避免线条过密。整个空白区域均可拖动平移，指针在画布外释放或窗口失焦时清除拖动状态。视口操作不修改已保存图或历史快照。
- 节点按标题栏、端口行、配置控件自上而下排列；端口标签保留在节点内部。配置直接在节点上编辑，不再提供单独的设置按钮或弹窗。控件按能力目录字段生成：文本和数字直接输入、选项下拉选择、布尔值切换，JSON 使用节点内的多行编辑区；字段名称和选项标签随界面语言切换，未知扩展保留目录原文。
- 节点可以拖动右边、下边或右下角调整大小；拖动热区透明，右下角仅在节点内部显示小型斜线标记，不遮挡圆角边框。尺寸手柄获得键盘焦点后，方向键每次调整 10 个画布单位，按住 Shift 调整 50 个单位，Home 恢复内容最小尺寸。最小尺寸结合目录布局与标题、端口、控件及预览面板的实际占用计算，切换语言或出现错误提示时重新计算；不能缩小到遮挡操作元素。长文本、JSON 和媒体内容仍可在各自控件内部滚动，不按整段数据无限撑高节点。额外空间用于扩展编辑和预览区域；连线、添加节点避让和适应画布使用相同的实际尺寸。
- 自定义尺寸随工作流保存；旧无尺寸节点继续按内容显示，不为测量而回写历史。仅调整大小属于布局变更，未保存时有离开保护，但不会改变执行版本或把已有运行结果判为过期。保存、校验、上传或运行期间锁定尺寸编辑，指针在画布外释放或窗口失焦时结束调整。
- 输入即时更新内存草稿，通过工具栏统一“校验并保存”；不需要逐节点应用设置。无效或未完成的数字/JSON 输入保留供修正，参与未保存判断和离开确认，并阻止校验或保存请求；目录约束负责即时反馈，复杂语义仍由后端最终验证。切换节点或界面语言保留正在编辑的内容。控件内的选择文字、键盘输入和滚动不触发节点拖动、连线或删除；保存、校验及活动运行期间锁定配置编辑。
- 未保存草稿不能运行；校验或保存冲突失败保留草稿。切换音频/项目或返回列表时先确认放弃，确认前不改变原视图。

## 运行与结果

- 图按项目保存，运行绑定输入节点选定的音频及已保存图版本；旧 `{}` 输入使用运行音频上下文，保存的快照不受后续编辑影响。
- 音频、文本预览在对应节点内显示当前所选运行的结果，刷新后可以从音频历史中重新查看。更改输入或其他执行配置后，旧结果标记为历史版本；尚无结果时不显示虚假的历史版本。文本按纯文本展示，音频使用浏览器播放器；文件缺失、加载失败或浏览器不支持该格式时明确提示并可重试，不自动重跑模型或改写任务状态。渲染组件通过注册表扩展，未知渲染器明确提示。
- 活动运行期间画布只读，并阻止离开、切换音频或选择另一段历史。完成或取消后可编辑并创建新运行，旧记录不被改写。
- 通过 REST 轮询当前运行；切换后的旧响应不能覆盖新视图。刷新后从该音频的运行列表恢复查看，不使用旧阶段 WebSocket 更新节点图。
- 结果区显示等待、运行、完成、失败、阻塞、取消和中断；错误定位到节点。独立分支的成功结果仍可下载。
- 下载按当前所选运行/节点查询文件可用性，区分检查中、缺失、检查失败和可下载；失败可重试。不能仅凭历史快照地址假定文件仍存在，输入节点没有下载产物。
- 运行结束后可调整图并从输入重新跑；尚无指定节点续跑、缓存复用或手动历史清理。

## 安全与回归

- 不提供本地模型/可执行文件路径、识别能力发现、真实 Provider 或云端密钥设置。后端 Profile CRUD 留存不等于有云端配置界面或调用能力。
- 删除项目二次确认，说明会删除全部音频和产物；任一音频忙碌时禁止删除。
- 回归覆盖默认直通、Mock 字段与目录驱动扩展、校验/保存冲突、草稿导航、逐音频和历史隔离、真实产物下载、取消及上传重试。
- 语言回归覆盖偏好读取与存储受限、消息键与插值一致性、既有错误实时切换、上传中切换及重试快照、工作流草稿与未知扩展展示。
- 旧配置和数据不自动改写。旧固定 Pipeline 已退役，不能从新界面继续其任务；云端 ASR 尚未实现。
