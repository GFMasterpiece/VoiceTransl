# VoiceTransl 前端工作流

本文描述当前 WebUI。资源/API 见[多音频项目契约](voicetransl_multi_audio_project.md)，执行与存储见[架构约定](architecture.md)，计划见[线路图](roadmap.md)。

## 主流程

项目列表 → 创建空项目 → 在音频输入节点准备一份或多份音频 → 编辑节点图 → 校验并保存 → 统一点击运行 → 查看单运行或批次历史与产物。

- 项目列表使用服务端分页，默认每页 20 项；创建/删除后刷新有效页。分页请求按代次隔离，过期响应不能覆盖当前列表。
- 新建项目使用名称输入弹窗，不再切换到独立创建页；列表和画布均可打开。弹窗只填写名称，不选择语言或导入音频，也不依赖上传策略接口。创建成功后直接进入默认节点图；失败保留名称供重试。尚无音频时也能编辑、保存图；没有可用输入时不能运行，音频统一在输入节点中选择或上传。
- 新运行由输入节点显式绑定的音频决定；历史音频选择器独立控制查看上下文，切换保留草稿和绑定。旧 `{}` 输入使用所选音频上下文。不同音频的时间轴、历史及产物不合并。
- 新建项目不发送源语言或目标语言，项目对应元数据保持 `null`，不按界面语言或固定语言补值。源语言在音频输入节点上传时明确提供，处理节点的语言按各自契约配置；目标语言留给未来翻译节点，当前没有翻译节点。旧项目已有语言字段继续读取并可用于输入节点预填，不改写旧数据。
- 创建不再发送或展示 `preset`。旧项目保留该字段不等于仍能切换旧处理预设。
- 显式资源清单决定本次输入：一项走单运行，多项使用同一快照逐文件运行；旧空配置才使用焦点音频。画布和运行面板共用执行逻辑，批次面板只管理记录，没有旧五阶段工作区或旧批量阶段执行。
- 项目工作区占满浏览器视口，以节点画布为主体；项目列表保留独立入口，新建项目通过弹窗完成。紧凑工具栏提供返回项目、项目名称、历史音频选择、语言、校验保存、视口控制及运行/产物/日志入口，不再常驻大标题、节点检查侧栏或下方结果区。
- 打开、取消或关闭新建弹窗不卸载当前画布，也不丢弃草稿、节点输入、音频绑定或视口位置；真正提交并切换项目时仍检查未保存更改及运行、上传等忙碌状态。创建请求期间锁定重复提交、关闭及导航；弹窗支持名称自动聚焦、键盘焦点圈定和空闲时 Escape/背板关闭，关闭后回到原入口。

## 界面语言

- 顶栏支持简体中文与 English，上传或节点运行期间也可以切换；界面文本、无障碍标签、确认弹窗、状态及已知错误提示随之更新，日期和数字按当前语言格式化。
- 首次打开按浏览器语言列表选择第一个支持的语言，均不匹配时使用简体中文；之后优先使用本机浏览器保存的选择。偏好保存在 `localStorage` 的 `voicetransl.locale`，不写入项目。浏览器禁止存储时仍可在当前页面切换。
- 切换语言不重新加载工作区，不清空表单、节点上传状态或未保存节点图，不改变文件、当前音频、运行记录及提交快照。界面语言与音频源语言、旧项目语言元数据、Mock ASR 的结果语言相互独立。
- 内置节点和已知错误码有对应译文。节点类型、端口、配置键和选项值继续使用原协议标识；未知扩展的节点、字段、选项和错误诊断保留服务端原文，不阻止其按能力目录接入。用户填写的项目名、文件名和节点配置不翻译。
- 消息集中在 `frontend/src/i18n/messages/`，按通用、项目、工作流、编辑操作和批处理等功能组织。新增文案须同步两种语言的键和插值参数；扩展语言时同步语言注册、检测、选择入口及测试，不在组件中另建文案名单或以译文判断业务逻辑。

## Qwen 与服务连接

- 顶栏及云节点内可打开服务连接弹窗，创建、编辑、启停、删除非密钥连接。服务类型、默认地址/环境变量名/超时及节点可选连接由后端目录声明派生，不在前端复制服务商或模型名单。
- Qwen 节点直接编辑连接、模型、语言及 JSON 附加参数。语言留空使用当前音频已声明语言，接外部语言参数后按已有规则隐藏手填输入框；连接引用不开放参数线。
- 连接和能力刷新仅替换缓存，保留图草稿、撤销、待上传 File 及视口；失效连接保留原 ID 并显错。读取过程中禁止并发写连接，但可关闭窗口；实际写请求期间禁止关闭或重复提交。失败保留表单，启用不等于凭据已经验证。
- 当前节点/待运行说明显示目标域名、人工声明地域、输入文件数，临时文件和取消边界来自目录 `data_handling`。历史及批次详情显示其冻结连接，不能拿最新连接或当前目录规则反推旧历史。
- 统一运行沿用单/批处理入口；云端识别提交不自动重发，取消会停止本地请求，远端 RUNNING 可能继续。没有每次运行的额外审批弹窗；设置与限制见[服务连接](provider_profiles.md)。

## 上传与重试

- 音频输入节点保留当前音频/单个资源方式，也可切换“多个文件 / 文件夹清单”，选择多个文件、反复添加目录或添加项目已有资源；每条音频保留原始文件名。
- 上传扩展名与大小限制来自 `upload-policy`，加载失败可重试，成功前不提交。该规则不等于 MIME 或音频内容解码校验。
- 不同同名文件可以作为独立音频追加到同一项目，不覆盖已存在资源。旧批量上传工具与 multipart 创建接口仅保留兼容，当前创建弹窗不提供批量导入界面。
- 音频输入节点中可选择项目已有音频、选择新文件或拖放单个文件；源语言明确显示且可编辑。节点上传直接向已有项目追加资源，显示上传中状态，失败保留文件可重试；上传成功后绑定新资源并标记图草稿，仍需保存才可运行。上传中锁定编辑和导航，浏览器离开也有保护；不伪造上传百分比。
- 节点上传失败保留待传文件，允许修正源语言后在原项目重试；已成功追加的资源不会因后续绑定保存失败而删除或复制。
- 上传期间锁定相关编辑与导航，并提供浏览器离开提示；刷新后从项目中访问已保存文件，不恢复内存中的待传文件。

## 文件夹批处理

- 在音频输入节点切换到“多个文件 / 文件夹清单”，多次添加文件夹、选择多个文件或添加项目已有资源。目录默认包含子目录，也可关闭；每次选择单独标识来源，保留相对路径和同名资源。
- 默认源语言可应用到待上传项，逐项修正后预检；格式和大小仍来自服务端上传策略。允许勾选排除、移除及上传失败重试，成功资源保留，不因关闭面板再次上传。来源路径仅是元数据，不能填写任意本机路径让服务端扫描。
- 上传与执行分开。上传成功且选中的资源 ID 按顺序写入图，清单编辑可撤销/重做但不删除资源；校验并保存后点击画布或运行面板的“运行”。一项走普通运行，多项提交一次批次，每份文件各跑一遍同一图；显式空清单及仍选中的待上传/失败项会阻止运行，不能退回焦点音频或静默少跑。清单每页 20 项，列表内部滚动，模式/语言/导入/上传等控件参与节点内容最小尺寸测量。
- 批次由服务端调度，面板显示分页历史、逐项运行 ID/状态/错误和汇总进度，支持取消、失败/中断重试及 ZIP 下载。重试用原批次快照创建新批次；部分完成项不自动重试，可在新清单中明确重新运行。
- 批次窗口不再提供导入和开始按钮，保留历史、进度、明细、取消、重试、未确认请求恢复及 ZIP。关闭窗口不改变输入节点清单；已保存清单刷新后按图恢复，未上传 File 只在当前编辑器会话。已经提交的批次继续执行，重新打开或返回项目后从 REST 恢复状态。后台批次允许离开工作区和编辑公共图，排队文件仍用原快照。未纳入该批次的其他音频可以独立运行，共享全局并发额度；后端以实际音频预留最终裁决冲突。
- 未上传文件及未确认提交的请求需要离开保护，上传或提交过程中不能切换项目；浏览器刷新不会恢复内存中的 File，已上传资源可从项目重新添加。批次提交响应丢失时保留原请求编号与载荷，明确重试而不生成重复批次。
- 批次详情不回填当前草稿，不把旧图配置替换为最新默认值；界面切换中英文保留清单、语言、请求和状态。

## 节点图

- 默认只有 `audio_input -> audio_output`，两端使用 `audio` 端口，不要求加入处理节点。
- “当前文件信息”提供当前运行音频的文件名、主干、源语言、相对路径和来源目录名五个字符串输出，可用普通参数线控制命名和语言；没有来源目录的旧音频仍可使用。
- 可添加音频预览、文本预览节点作为分支终点。音频输入可直连音频预览；Mock 或 Qwen ASR 的转写均可连接文本预览。只有预览、没有导出节点的图也可保存运行。音频输入负责上传和资源绑定，不内置预览播放器。
- 可选 Mock 预处理仅复制原字节；Mock ASR 生成固定示例文本，`language` 只标注结果语言。它们不是实际预处理/识别能力。
- Mock 预处理只保留 `provider=mock`；Mock ASR 只保留 `provider=mock` 和 `language`。不显示模型、后端、VAD、分段、Profile、采样率、声道或源文件删除设置。
- 音频/文本输出可选择原名或前缀编号模式；新输出默认前缀编号，例如 `copy_00001.wav`、`text_00001.srt`，实际扩展名仍由音频或文本格式决定。编号按输入顺序固定，重试保留原编号；缺少模式的旧图保持原名称。前缀仍可由参数线提供，配置保留前缀，产物记录完整名称。文本输出支持 TXT/SRT/VTT/LRC，用于导出统一转写结果；没有翻译、对齐或视频节点。
- 节点类型、分类、端口、数据类型、源标记、字段约束、图限制及默认图来自 `/capabilities` 的 `workflow` capability schema `1.8`；端口以 `{id, type_id, label, capability_requirements}` 发布，图只保存稳定 ID。前端按父类型和能力要求作即时提示，不复制执行逻辑、格式白名单、默认配置或数量规则。目录无效/读取失败明确报错并允许重试，后端验证为最终权威；此版本不同于持久化 schema `1.0`。
- 添加节点菜单按后端 `category: null | {id,label}` 分组：输入、预处理、语音识别、预览、输出、参数；Qwen和Mock识别同属语音识别，Mock名称明确标记。类别按目录首次出现排序，搜索同时匹配节点名、类型和类别名，空组隐藏；标题不参与键盘选项导航。旧 `1.2–1.7` 目录及未分类扩展显示“未分类”，未知类别保留服务端标签；不按节点名猜类别，分类不写入草稿或运行快照。
- 兼容 capability `1.2/1.3` 单端口、`1.4` 命名多端口、`1.5` 参数、`1.6` 集合及 `1.7` 连接目录，拒绝 `1.0/1.1` 和未知版本。`1.4` 的 `required_input_ports` 必须存在、唯一且匹配 `required_inbound`；`1.5` 要求字段显式声明可空 `input_port` 和节点声明 `is_parameter_source`，参数绑定须存在、唯一、可选且类型兼容。旧目录没有参数声明时按无参数输入解释。
- `1.6` 资源声明使用 `resource_input={resource_type,config_key,collection_key}`，集合键可空；单项和集合字段都由资源控件编辑，复制/导出按声明清除，不开放参数线。字段可空的 `creation_default` 仅用于新建节点，旧配置显示和读取仍用 `default`，不能用新默认值推断旧运行。预览仍由可空的 `presentation.preview` 声明渲染器，前端不按节点名称特判。详情见[输入清单规格](../spec/node-batch-input.md)。
- 在画布空白处右键打开添加菜单，节点列表和限制来自能力目录；新节点按右击处的画布坐标放置，并避让已有节点。菜单支持搜索和键盘操作，另保留添加按钮作为触屏及键盘入口。节点上右键可删除节点及其连线，仍检查目录的可删除标记并确认；输入框、文本编辑区及媒体控件保留原生右键操作。菜单在屏幕内限位，取消或点击外部不修改图；保存、校验、上传及运行期间禁止修改节点。
- 支持节点添加/删除、拖动布局、拖拽连线/断开及缩放平移。可以从源输出端口拖到目标输入端口，也可以从目标输入端口拖到上游输出端口；保存的边始终为输出到输入，拖动方向不改变数据处理方向。释放到空白处、画布外或同方向端口时取消待连接状态。端口拖拽不会触发节点移动，也不会提前断开已有连线；只有合法新连接完成时才替换目标端口的原有入边，保留目标节点其他端口的连接；达到边数上限时仍允许合法替换原线。新增节点不暗中替换原有连线；连线由后端根据源端口和目标端口绑定的逻辑 `type_id` 判断兼容，不能仅比较端口名称。具体音频实现可以通过父类型或能力契约满足 `audio`，因此不要求所有音频对象使用同一个 Python 类。画布按目录顺序展示全部输入/输出端口，同一节点对可连接不同端口；每个输入最多一条线，一个输出可分支。多端口连接必须选择实际端口，不能默认取第一个。图的必填连接与执行有效性最终由后端校验。
- 网格平铺覆盖整个可视画布，随节点图同步平移、缩放，容器变宽或变高后自动覆盖新增区域；低倍缩放使用更疏的网格，避免线条过密。整个空白区域均可拖动平移，指针在画布外释放或窗口失焦时清除拖动状态。视口操作不修改已保存图或历史快照。
- 节点按标题栏、多行端口、配置控件自上而下排列；端口标签保留在节点内部，可选输入明确标注；设置和预览从全部端口行下方开始。行数同时参与最小尺寸、实际内容测量、连线锚点和节点避让，保持单端口节点原有布局。配置直接在节点上编辑，不再提供单独的设置按钮或弹窗。控件按能力目录字段生成：文本和数字直接输入、选项下拉选择、布尔值切换，JSON 使用节点内的多行编辑区；字段名称和选项标签随界面语言切换，未知扩展保留目录原文。
- 节点可以拖动右边、下边或右下角调整大小；拖动热区透明，右下角仅在节点内部显示小型斜线标记，不遮挡圆角边框。尺寸手柄获得键盘焦点后，方向键每次调整 10 个画布单位，按住 Shift 调整 50 个单位，Home 恢复内容最小尺寸。最小尺寸结合目录布局与标题、端口、控件及预览面板的实际占用计算，切换语言或出现错误提示时重新计算；不能缩小到遮挡操作元素。长文本、JSON 和媒体内容仍可在各自控件内部滚动，不按整段数据无限撑高节点。额外空间用于扩展编辑和预览区域；连线、添加节点避让和适应画布使用相同的实际尺寸。
- 自定义尺寸随工作流保存；旧无尺寸节点继续按内容显示，不为测量而回写历史。仅调整大小属于布局变更，未保存时有离开保护，但不会改变执行版本或把已有运行结果判为过期。保存、校验、上传或运行期间锁定尺寸编辑，指针在画布外释放或窗口失焦时结束调整。
- 输入即时更新内存草稿，通过工具栏统一“校验并保存”；不需要逐节点应用设置。无效或未完成的数字/JSON 输入保留供修正，参与未保存判断和离开确认，并阻止校验或保存请求；目录约束负责即时反馈，复杂语义仍由后端最终验证。切换节点或界面语言保留正在编辑的内容。控件内的选择文字、键盘输入和滚动不触发节点拖动、连线或删除；保存、校验及活动运行期间锁定配置编辑。
- 允许参数线的字段会显示额外的命名输入端口；字段与端口名称由目录映射，可以不同。首批支持 Mock ASR 语言、两类输出文件名及文本输出格式；音频资源绑定和固定 Mock Provider 保持原控件。连接后隐藏对应手填字段整行，不保留空白占位；端口及其悬停/辅助说明仍可查看参数用途和上游来源。手填后备值继续保存在配置中，合法断线后恢复原控件和原值。节点最小尺寸按可见内容重算，保留用户显式设置的尺寸；不因显示变化改写配置、布局或运行快照。后备配置仍须合法；隐藏控件或接线不会清除未完成输入，也不会绕过校验。
- 字符串、整数、数字和布尔值节点可提供参数，节点菜单和字段来自后端目录；参数根不计为音频资源源，不改变运行所绑定的音频。界面语言不会改变数值、布尔值或传递的字符串。
- 未保存草稿不能运行；校验或保存冲突失败保留草稿。切换音频/项目或返回列表时先确认放弃，确认前不改变原视图。

## 编辑器常用操作

- 工具栏的“编辑”菜单集中提供撤销、重做、全选、复制、粘贴、复制为新节点、删除及工作流 JSON 导入/导出，并显示快捷键。
- 普通点击选择单个节点，Shift 点击切换选择成员；Shift 在空白处拖动框选，普通空白拖动继续平移，空白单击清空选择。拖动已选节点会移动整组选区并保持相对位置；批量删除保留目录声明不可删除的节点并提示。
- 撤销/重做保存本次项目编辑会话最近 50 步。节点增删、参数、连线、布局/尺寸、粘贴和导入均可撤销；一次拖动或整组编辑只算一步，连续字段输入合理合并。保存后仍可撤销，是否未保存始终与最近成功保存的图比较；重新加载、离开或放弃草稿清空本地编辑历史。
- 复制仅携带选中节点和内部连线，粘贴/复制为新节点重新分配 ID，保留参数后备值、相对布局和显式尺寸。系统剪贴板不可用时使用应用内会话缓冲并提示。数量、源及实例限制仍来自后端目录，不能复制出第二个唯一音频源；失败整批拒绝。
- 导出当前草稿为 `workflow.json`，内容只含有版本标识的节点、配置、布局和命名端口边，不自动保存或运行；项目音频绑定依据目录元数据清除，不包含音频文件、项目修订、运行历史或产物。
- 导入只接受同版本 VoiceTransl 工作流格式，文件上限 4 MiB；先检查结构和目录兼容性，再显示节点/连线数量和替换说明。确认后整体替换为可撤销草稿，取消和读取失败不改原图；仍需用户校验并保存。可以导入未连完或字段尚待修正的草稿，原有保存/运行规则继续生效。资源需在本项目绑定或使用当前运行音频上下文。
- 选择、视口和内容测量不进入编辑历史；编辑历史不撤销音频上传、服务端保存或运行。加载、保存、校验、上传和活动运行期间禁用图修改；输入、媒体控件及弹窗保留原生快捷键。文件异步读取和剪贴板响应不能覆盖后来切换的上下文。格式及验收见[编辑器规格](../spec/editor-operations.md)。

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z；另支持 Ctrl+Y |
| 全选节点 | Ctrl/Cmd+A |
| 复制 / 粘贴节点 | Ctrl/Cmd+C / Ctrl/Cmd+V |
| 复制为新节点 | Ctrl/Cmd+D |
| 删除所选节点 | Delete / Backspace |

## 运行与结果

- 工具栏的运行、产物、日志按钮分别打开弹窗；运行窗口保留启动、取消、当前状态及历史选择，产物窗口保留实际文件可用性检查、下载和重试。关闭弹窗只收起界面，不停止轮询或运行，也不丢失未保存图、节点输入或音频绑定。
- 弹窗支持关闭按钮和 Escape、键盘焦点圈定及关闭后返回触发按钮；打开时背景不可交互。弹窗和右键菜单内的操作、滚动不会误触画布平移、节点拖动、连线或删除。
- 运行/日志详情另展示所选运行记录的字段来源及实际执行配置；连接来源显示源节点和端口，手填来源明确标注。排队尚未解析与旧历史未记录分别显示，失败候选值不冒充成功执行值。所有内容按文本渲染，不能用当前节点默认值或草稿推测历史。
- 日志窗口基于当前所选运行已有的创建、开始、结束时间，节点状态及错误显示运行记录；缺失的时间明确标为未记录，不补造事件或时间戳。此入口不等同于服务端控制台日志或完整事件流，当前未增加独立日志 API。切换历史音频或运行后，日志与产物同步切换上下文。
- 图按项目保存，运行绑定输入节点选定的音频及已保存图版本；旧 `{}` 输入使用运行音频上下文，保存的快照不受后续编辑影响。
- 音频、文本预览在对应节点内显示当前所选运行的结果，刷新后可以从音频历史中重新查看。更改输入或其他执行配置后，旧结果标记为历史版本；尚无结果时不显示虚假的历史版本。文本按纯文本展示，音频使用浏览器播放器；文件缺失、加载失败或浏览器不支持该格式时明确提示并可重试，不自动重跑模型或改写任务状态。渲染组件通过注册表扩展，未知渲染器明确提示。
- 活动运行期间画布只读，并阻止离开、切换音频或选择另一段历史。完成或取消后可编辑并创建新运行，旧记录不被改写。
- 通过 REST 轮询当前运行；切换后的旧响应不能覆盖新视图。刷新后从该音频的运行列表恢复查看，不使用旧阶段 WebSocket 更新节点图。
- 运行窗口显示等待、运行、完成、失败、阻塞、取消和中断；错误定位到节点。独立分支的成功结果仍可在产物窗口下载。
- 下载按当前所选运行/节点查询文件可用性，区分检查中、缺失、检查失败和可下载；失败可重试。不能仅凭历史快照地址假定文件仍存在，输入节点没有下载产物。
- 运行结束后可调整图并从输入重新跑；尚无指定节点续跑、缓存复用或手动历史清理。

## 安全与回归

- 提供独立 Qwen 云端识别及服务连接管理，不提供本地模型/可执行文件路径、模型能力自动发现、其他云协议或实际密钥输入框。连接只存服务端环境变量名，模型自由填写但必须符合当前 Filetrans 协议。
- 删除项目二次确认，说明会删除全部音频和产物；任一音频忙碌时禁止删除。
- 回归覆盖默认直通、Mock 字段与目录驱动扩展、校验/保存冲突、草稿导航、逐音频和历史隔离、真实产物下载、取消及上传重试。
- 语言回归覆盖偏好读取与存储受限、消息键与插值一致性、既有错误实时切换、上传中切换及重试快照、工作流草稿与未知扩展展示。
- 旧配置和数据不自动改写。旧固定 Pipeline 已退役，不能从新界面继续其任务；云端识别使用独立 Qwen 节点，不恢复旧 Provider 设置。
