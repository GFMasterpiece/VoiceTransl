# 全局设置

在主页点击“全局设置”，一级导航为通用及有默认值的节点类别，类别内选择具体节点。窗口切换类别或类型时保持尺寸；标题、导航和底部按钮固定，长表单在内容区滚动。小屏按视口约束。关闭未保存更改会确认，提交防重复，读取期间可以关闭。

## 通用

浏览器后端地址在主页连接状态入口设置，与本面板的云端节点连接分开。切换后端会刷新并读取目标服务自己的并发、模板及默认凭据；界面语言、调试模式和节点删除确认继续使用浏览器偏好。

| 项目 | 初值 | 生效方式 |
| --- | --- | --- |
| 界面语言 | 浏览器保存值或首次检测 | 立即切换并保存在浏览器，主页和画布不重复显示选择器 |
| 调试模式 | 关闭 | 立即显示/隐藏 Mock 的添加入口，不删除当前图的节点；当前 Mock 无默认模板 |
| 删除节点时不再确认 | 关闭 | 勾选立即生效并保存在当前浏览器，单个、批量、菜单及键盘删除跳过确认；删除仍可撤销 |
| 同时上传文件数 | 3 | 1–32，每次启动上传捕获并固定队列并发 |
| 工作流执行并发 | 启动配置，仓库缺省 1 | 保存后调整全局许可；不取消已执行任务 |

上传只准备资源，不自动运行。文件总数与并发数不同，清单上限仍由后端验证。

服务端设置存于数据根 `settings-v4.json`，schema 为 `4.0`。首次没有新文件时使用启动配置及当前节点声明；不读取任何旧命名空间（包括 `settings.json`、`settings-v2.json`、`settings-v3.json`），不转换旧处理节点模板。保存后的并发优先于启动初值，重启恢复。浏览器语言、调试开关和节点删除确认不进入服务端设置或项目，不使服务端表单变脏；无需点击保存，浏览器存储不可用时仍对当前会话生效。

## 配置节点默认值

默认模板按 LLM/ASR 服务、模型以及实际有字段的节点分别维护：

- LLM 服务：API base 和默认 Key；ASR 服务：识别协议、对应地址和默认 Key。没有地域字段。
- LLM 模型与 ASR 模型：分别配置自由模型名及 JSON 请求参数，不能混用。
- LLM 翻译：可直接填写的 context 默认值，仍可在图中接字符串覆盖。
- JSON节点：JSON对象及合并策略。文本拼接仅保留图内的动态输入项，按顺序直接连接，无分隔符及全局默认模板；不提供专用上下文模板。文本值可直接提供公共上下文。
- 翻译/识别执行参数：超时及适用的分批、上下文片段、有限重试。

字段和类别均由后端声明，前端不建立节点/服务商名单。处理节点没有配置字段时不占一个空默认设置栏；类别内选择不同配置类型，而非为每个类型增加顶级标签。模板按节点类型分别保存，不是按协议建立多份连接 Profile。

仅从添加菜单新建节点时复制模板。已有节点、复制/粘贴/导入和历史运行不补读当前默认值。新连接创建时捕获默认 Key 版本，首次保存图时物化为其项目/owner 独享版本；显式共享连接只复用图中这个版本，不会让全局 Key 成为运行时后备。

默认密码为空表示保留，替换和清除分别显式操作；成功清空密码输入，失败保留以重试。切类别/类型不丢其他表单和密码。默认 Key 在 `.default_credentials/` 独立加密，连接凭据在 `.credentials/`；备份需保护各自主密钥与密文，版本暂不自动回收。

## 接口与恢复

- `GET /api/v1/settings` 从能力目录 `1.18` 的声明派生通用项、模板字段、revision及已配置状态，不返回真实 Key。
- `PUT /api/v1/settings` 使用 schema `4.0`、预期 revision、稳定请求 ID 及只写密钥更新；原子发布，同请求可重放，冲突要求刷新。
- 工作流的 `use_default` 携带创建时捕获的版本，由后端校验类型并物化；运行不读取默认模板。
- 设置读取失败不能当作空缓存继续创建节点。新文件损坏、未知 schema、类型或字段明确拒绝并保留原文件；新增声明仅补齐内存视图，不重写既有设置。

当前范围见[服务与字段输入规格](../spec/service-families-field-inputs.md)，早期设置里程碑见[全局设置规格](../spec/global-settings.md)。

已注册节点不再声明任何默认字段时，加载设置仅在内存忽略其退役模板，不修改原文件或其他默认值及凭据；完全未知节点和活跃模板中的未知字段仍拒绝，保存请求须使用当前目录。
