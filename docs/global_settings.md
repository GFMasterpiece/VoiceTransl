# 全局设置

在项目主页点击“全局设置”，一级导航为通用及有默认设置的节点类别，类别内选择具体节点类型，统一点击保存。窗口在切换类别或节点类型时保持相同尺寸，标题、类别栏和底部按钮固定，长表单只在内容区滚动；小屏按可用视口约束尺寸。关闭尚未保存的更改会请求确认；读取中的面板可以关闭，提交时防止重复操作。

## 通用

浏览器连接的后端地址在主页连接状态入口设置，独立于本面板。切换后端会刷新并读取目标服务自己的并发设置、节点默认值及默认凭据；界面语言和调试模式继续采用当前浏览器偏好。

| 项目 | 初值 | 生效方式 |
| --- | --- | --- |
| 界面语言 | 浏览器已保存偏好或首次检测结果 | 在全局设置的通用页选择，立即切换并保存在当前浏览器，无需点击保存；主页及工作区不重复提供选择器 |
| 调试模式 | 关闭 | 立即显示或隐藏 Mock 节点的添加及默认设置入口，浏览器记住选择；不改变已有图与运行 |
| 同时上传文件数 | 3 | 1–32，每次开始上传时采用已加载策略并固定该队列的并发 |
| 工作流执行并发 | 启动配置，仓库缺省 1 | 保存后调整全局许可，普通运行与批次共用；调低不会取消已经执行的任务 |

上传仅准备项目资源，仍需保存工作流并点击运行。文件总数不受上传并发数限制，输入清单上限继续由后端验证。

并发和节点默认设置保存在数据目录的 `settings.json`。首次尚无文件时使用启动配置；支持 `app.upload_concurrency`、`VOICETRANSL_UPLOAD_CONCURRENCY` 及原工作流并发配置。保存后的这两项优先于启动初值，重启继续恢复；其他服务配置沿用原路径。界面语言继续复用浏览器 `voicetransl.locale` 偏好，调试开关也是本地显示偏好，二者不进入设置 API、项目或运行快照，不使服务端表单变脏。

## 节点默认值

“翻译”类别提供 LLM 翻译新节点的默认连接、模型、源/目标语言、术语表、分批参数和独立默认 Key。未填写的连接、模型和目标语言不会自动猜测；模板与草稿可保存，执行前必须提供。其创建时版本冻结、节点独享物化及复制粘贴规则与语音识别相同。

“语音识别”类别内选择 Qwen Filetrans 或 Qwen Streaming；调试模式开启后才显示 Mock ASR 默认语言。两种 Qwen 的连接字段统一为地址、超时、适用的地域、API Key，处理参数统一为模型、语言及附加参数；Streaming 没有地域字段。模型为自由文本，语言可搜索候选或使用自定义代码；具体连接和输入限制见[节点连接](node_connections.md)。类别来自后端声明，不为每个节点建立顶级标签。

分类合并导航，不共享不同类型的配置和密钥。切换类别、类型、语言或调试模式均保留各自未保存字段与私有 Key；关闭调试后，隐藏的默认设置仍原样参与保存，已有图中的 Mock 节点和历史继续保留。展示规则见[设置分类与调试节点规格](../spec/settings-node-organization.md)。

通过添加菜单创建节点时，复制当前默认配置。已有节点、历史、复制粘贴及导入不会被重新套用默认值；各节点仍能单独修改。设置字段由后端节点注册声明，增加已声明支持的默认字段无需在前端新增节点类型分支。

默认 API Key 留空保持，输入替换或显式清除。新节点保存时会把创建当时的默认版本复制为本节点独享凭据；后续修改或清除全局默认，不影响已有节点和已提交运行。创建后未保存的节点也保持创建时版本，不能在保存时换用最新默认。

默认密钥加密存放在 `.default_credentials/`，节点密钥仍在 `.credentials/`，两者各有主密钥。设置文件只保留默认版本令牌，图及快照只保留物化后的节点引用。备份须一并保护主密钥与密文；读取整个数据目录可同时取得它们，此同机加密不抵御数据根整体泄露。旧版本暂不自动回收。

## 接口和失败恢复

- 目录 `1.13` 起支持全局设置，当前 `1.15` 继续提供此能力并声明节点调试属性，持久化仍为 `1.0`。旧目录不推断未声明的能力。
- `GET /api/v1/settings` 提供 revision、通用字段/值和各类节点的字段、配置及密钥已配置状态，绝不返回明文密钥。
- `PUT /api/v1/settings` 提交通用配置、默认字段、预期 revision、稳定请求 ID 及只写密钥更新。文件原子发布；响应丢失时可使用原请求重试。冲突需刷新再修改，不静默覆盖其他更改。
- 工作流只写凭据更新的 `use_default` 携带创建时版本，由后端校验类型并物化到当前项目/节点，运行入口不读取全局默认设置。
- 设置读取失败不以空缓存创建错误默认节点。新增注册类型/字段只补齐内存读取视图，不重写旧文件；损坏文件、未知 schema 或未知字段明确拒绝，原文件保留。

范围和验收见[规格](../spec/global-settings.md)。
