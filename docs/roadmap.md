# VoiceTransl 开发线路图

> 状态快照：2026-11-09。记录已完成的主要阶段和接下来的方向；具体接口与行为以各专题文档为准。

## 已完成

- **多音频项目基础：**一个项目包含多个独立音频；支持上传、逐音频资源和节点运行历史。
- **界面国际化：**Web 界面支持简体中文 / English 切换、浏览器偏好检测与本地保存，覆盖项目、上传队列和节点工作区；切换保留表单、草稿和运行快照，未知扩展保留原标签。详见[前端工作流](frontend_workflow.md)。
- **节点工作流最小入口：**工作流以项目为范围保存，当前默认图为 `audio_input -> audio_output`；任务执行保存不可变图快照并保留运行历史。
- **节点资源与预览：**通过名称输入弹窗创建空项目，在输入节点上传或绑定项目音频并明确源语言；创建不再使用独立页面或要求源/目标语言与导入音频，旧项目语言和上传 API 保留兼容。独立音频/文本预览节点可以替代导出作为终点，结果按运行保存并在节点内展示，历史查看与当前输入绑定分离。详见[前端工作流](frontend_workflow.md)和[规格](../spec/node-resources-preview.md)。
- **画布工作区：**项目工作区使用全视口画布，支持右键添加/删除节点、按内容最小尺寸缩放节点及双向起拖连线；运行、历史、产物下载及运行记录收进独立弹窗，关窗保留草稿和后台轮询。日志当前展示运行与节点已有的时间、状态和错误。详见[前端工作流](frontend_workflow.md)。
- **节点模块化与多端口：**内置节点的配置、声明与执行入口独立维护，注册核心和调度器按统一契约工作；支持命名多输入/多输出、可选输入、分支汇合及按实际端口拖线。该里程碑建立目录 `1.4`，后续参数扩展使用 `1.5`；持久化 schema 和旧运行保持不变。详见[规格](../spec/node-modularity.md)。
- **节点参数连线：**新增字符串、整数、数字、布尔值节点，按目录声明给 ASR 语言、输出文件名及文本格式提供参数。接线保留合法手填值，断线恢复；排队冻结来源，执行副本合并及完整校验，运行/日志记录实际值。目录升级为 `workflow.schema_version=1.5`，旧图与历史保持可读且不补写。详见[规格](../spec/node-parameters.md)。
- **编辑器常用操作：**支持 50 步会话撤销/重做、Shift 多选/框选、整组拖动与保护节点批量删除；复制粘贴重映射节点和内部数据/参数连线，工作流 JSON 可导出与预览后导入为可撤销草稿。音频和运行历史不进入可移植文件，保存及快照语义保持不变。详见[规格](../spec/editor-operations.md)。
- **文件夹音频批处理：**由服务端固定图及清单、按全局并发逐文件运行，支持分页进度、取消、失败/中断重试和含版本清单的 ZIP；最初通过独立面板导入，当前入口见下一项。“当前文件信息”参数节点提供命名和语言。Windows Edge 已验证两个目录/23 份音频、丢失响应幂等及后台改图，首版单项目一个活动批次，大目录写入性能仍待独立优化。详见[规格](../spec/batch-processing.md)。
- **输入节点批导入与编号输出：**多文件/目录清单移入音频输入节点，成功资源 ID 随图保存并支持撤销/重做；统一运行入口按一项或多项选择普通运行或批次，管理窗口只保留记录操作。新输出默认采用前缀和固定编号，重试保留原序号；旧绑定、原名模式、已保存图及历史不补写。能力目录为 `1.6`，持久化仍为 `1.0`。详见[规格](../spec/node-batch-input.md)。
- **Qwen云端识别：**独立Filetrans节点、临时OSS上传、真实文本/时间戳、服务连接管理及非密钥快照已接入，沿用单/批次调度与编号导出。模型自由配置，目录1.7按声明发布连接选项与数据处理边界；取消回收本地请求，远端RUNNING可能继续。Windows模拟HTTP与真实Edge链路验收通过，未用真实账号调用付费服务。详见[规格](../spec/cloud-asr-qwen.md)和[设置](node_connections.md)。
- **节点功能分类：**添加及空白右键菜单按后端类别分组，Qwen与Mock识别同归语音识别；支持输入、预处理、预览、输出和参数分类、中英搜索及键盘选择。目录升级1.8，旧目录及未分类扩展显示未分类，不修改已有图或执行语义。Windows全量测试及Edge检查通过，详见[分类契约](../spec/node-modularity.md)。
- **节点内云连接与密钥：**Qwen 节点直接编辑地址、超时、地域及 API Key，密码随统一保存进入独立加密存储，图和快照仅存不可变引用，复制/导入导出剥离绑定。目录 1.9 最初保留过旧 Profile/env 路径，该兼容现已退役；存储边界见[节点连接](node_connections.md)。
- **节点表单布局：**统一上下排列的标签与整行输入，分组连接及处理参数，长说明可展开；按实际节点宽度测量换行，避免错误、帮助和缩放手柄重叠，旧尺寸只在显示时按内容约束。Windows 前端 448 项测试、构建及 Edge 11 种布局场景验收通过，详见[前端工作流](frontend_workflow.md)。
- **独立 Qwen 文件 Streaming：**新增 WebSocket 识别节点，每实例独立地址/Key，无 Profile/env 继承；PCM16 单声道 WAV 读取真实采样率，完成后复用字幕、预览和批次。目录 1.10，持久化不变，旧 Filetrans 数据/摘要不变；Windows 后端 644 项通过、4 项跳过，前端 457 项通过，Ruff、构建及真实 Edge/假平台单批运行、隔离、冻图与取消通过，未调用付费服务。范围见[规格](../spec/cloud-asr-qwen-streaming.md)。
- **移除旧服务连接：**删除全局 Profile 界面、CRUD、配置文件加载与环境变量备用，两种 Qwen 均只用本节点连接和密钥。目录 1.11，含旧字段的节点明确拒绝并要求重建，历史元数据及产物被动保留；历史不再把闲置旧地址当作实际目标。Windows 后端 614 项、前端 435 项通过，Ruff、构建及模拟平台浏览器验收通过，详见[规格](../spec/node-connections-only.md)。
- **精简节点界面：**移除字段解释、密钥保存/数据处理/取消帮助、清单提示和重复目标；密钥、取消与超时只显示短状态，运行窗口保留目标及文件数摘要。前端 435 项测试与构建通过，Windows Edge 中英切换、错误关联、私有输入及节点无重叠检查通过，执行和凭据机制不变。
- **可搜索语言候选：**识别、单文件源语言和清单默认/逐行语言共用后端 30 项常用候选，支持中英文、原名、代码和别名搜索，也可确认自定义代码。目录 1.12 按字段声明启用，搜索不写图，原语言验证和历史摘要不变。Windows 后端 616 项通过、4 项跳过，前端 461 项、Ruff、构建及隔离 Edge 上传/布局验收通过；范围见[规格](../spec/searchable-languages.md)。
- **主页全局设置：**统一调整上传与工作流并发，按后端声明配置三类 ASR 创建默认值及两类 Qwen 默认 Key。添加时复制普通默认值，保存时将冻结的默认 Key 物化为节点独享凭据；旧图、复制导入及运行不跟随全局变化。目录 1.13，单服务进程可动态调整执行并发，上传队列捕获已加载策略。Windows 后端 638 项通过、6 项跳过，前端 470 项、Ruff、构建与隔离 Edge 设置重试/节点独立凭据/四文件上传和动态降并发通过；见[使用说明](global_settings.md)与[规格](../spec/global-settings.md)。
- **运行基础：**Mock 节点验证图校验、调度、取消和持久化；Mock预处理只复制字节，Mock识别生成固定示例，不执行真实识别或转换。
- **兼容性基础：**项目/工作流 schema 采用严格同版本读取，不自动迁移或改写旧文件。详见[架构约定](architecture.md)。
- **维护入口收敛：**项目说明和协作规则以 Web 前后端为准，旧桌面功能停止维护；旧 PyInstaller 发布工作流改为 Web CI，配置 Linux/Windows 后端检查及 Linux 前端测试/构建。远端 CI 是否通过以 Actions 实际结果为准。
- **旧桌面遗留清理：**移除根目录桌面入口与运行时适配、GalTransl、旧插件、翻译指南、本地工具占位和测试音频、旧桌面测试、依赖锁文件、PyInstaller 配置及上游个人赞助配置。当前仓库维护 Web 源码与相应文档，许可证、来源说明和既有运行数据保留。

## 历史实现（已退役）

- 项目曾包含桌面字幕翻译程序、GalTransl、插件、本地工具入口及打包资源；桌面路径、工具查找与进程操作曾统一到 `desktop_runtime.py`，随后随桌面实现一并移除。历史实现通过 Git 追溯，不是当前 Web 依赖或能力来源。
- 早期 Web 版本曾提供固定的五阶段处理界面，以及可选的本地音频预处理、语音识别和字幕导出节点；随后改为以可视化工作流为主。真实处理 Provider 和五阶段入口现已退役，仍保留 Mock 验证节点；历史项目与任务文件不自动迁移。
- 首个音频直通里程碑建立了图校验、修订乐观锁、执行版本、独立运行历史、逐节点文件与安全下载；此后曾扩展真实处理节点。当时为收敛产品范围，仅保留音频直通与Mock，随后按独立规格接入本轮Qwen节点。退役规格摘要合并至本节，通过Git追溯。

## 当前整改

- **最小骨架边界：**当前默认音频直通，保留 Mock、独立 Qwen 识别、运行历史与产物下载；旧配置/Job 只读及独立翻译适配器留存。Profile API 和旧服务连接执行已移除，不迁移或改写既有项目与任务。
- **兼容性与扩展性：**既定验收项见[整改规格](../spec/compatibility-extensibility.md)。Qwen节点按独立规格验收，不代表其他云端或本地Provider已实现。

## 接下来

1. **Qwen真实账号验收：**用户配置后端密钥后，明确选择样本验证服务可用性、识别质量、配额与耗时；当前模拟测试不能代替付费服务验证。
2. **生产存储与长音频策略：**按实际部署需要评估稳定对象存储、模型限制及分块，不把临时上传视为生产高并发方案。
3. **后续工作流能力：**其他服务商/翻译节点、图重跑/缓存及历史清理应逐项明确契约，不自动恢复旧五阶段流程。

## 已知问题与暂缓事项

- **Qwen验证边界：**当前接入用户指定平台的 Filetrans 与文件 Streaming 协议，仅完成 Windows、模拟 HTTP/WebSocket 与浏览器验收，没有真实账号/计费/长音频质量实测。Filetrans 的远端 RUNNING 不能保证取消，临时文件不能立即删除；Streaming 仅支持 PCM16 单声道 WAV，不保证关闭连接即远端停止或撤回音频。
- **历史数据：**旧项目和任务文件保留原样，不自动迁移；旧五阶段 Web 执行入口从本轮起退役。若后续需读取/迁移旧任务，另行设计显式兼容方案。

## 暂不纳入首版

其他云端/本地 Provider、生产对象存储、独立说话人分离节点、自动语言检测、跨音频合并、麦克风采集及实时字幕界面。已有文件可使用独立 Streaming 节点；Qwen 可通过附加参数请求服务端说话人信息，但未做真实账号质量验收。后续先确认具体协议和验收范围，不以已有草案默认某个服务商已获批准。

## 长期产品目标

最终目标是提供类似 ComfyUI 的可视化节点工作流。当前支持音频直通、Mock和Qwen识别，不代表完整处理图已实现；后续按独立规格逐步扩展。目标范围和待确认问题见[产品目标](product_requirements.md)及[节点工作流规格](../spec/workflow-editor.md)。
