# 节点连接与云端处理

当前支持 Qwen Filetrans 与文件 Streaming 两种独立识别节点，均在语音识别分类。默认工作流仍为音频直通，Mock ASR 仍只产生示例。

另有“翻译”分类的 `llm_translate`，直接调用兼容 Chat Completions 的 API。每个实例分别配置 API base、模型、语言、超时及 Key，复用相同的节点独享凭据、默认模板、保存和冻结机制；不使用 Qwen 连接，也不恢复全局 Profile 或环境变量备用。地址、模型和目标语言默认留空，允许先保存未完成配置，运行前检查必填值。翻译设置和当前文本见[翻译说明](translation_providers.md)。

## 配置与运行

1. 在音频输入节点上传或选择音频并明确源语言，添加相应 Qwen 节点，连接文本预览或文本输出。
2. 在该节点直接填写地址、总超时、API Key、模型及可选语言。Filetrans 可填写地域，地域只作人工声明，不决定路由或证明实际处理区域。
3. 校验并保存图，再运行；输入一份文件走普通运行，多份文件走固定快照批次，输出继续按前缀与稳定编号命名。

节点界面只保留标签、控件、简短状态与必要错误，不展示密钥保存、数据处理/取消或字段说明；技术细节保留在本文。运行详情保留目标及文件数摘要。

识别语言与音频源语言均可搜索后端提供的语言候选，选择后保存代码，也可确认自定义代码。识别语言留空仍使用输入音频语言，源语言仍必填；候选不表示所选模型一定支持该语言。

| 节点 | 默认地址 | 推荐模型 | 输入与结果 |
| --- | --- | --- | --- |
| Qwen Filetrans | `https://maas.qianwenaiapi.com/api/v1` | `qwen-audio-3.1-asr-flash-filetrans` | 获取临时上传凭证、上传、异步识别、轮询及下载结果 |
| Qwen Streaming | `wss://maas.qianwenaiapi.com/api-ws/v1/inference` | `qwen-audio-3.0-asr-flash-streaming` | 仅 PCM16 单声道 WAV，读取采样率并按音频速率传输，任务完成后发布最终结果 |

模型名可修改，没有永久白名单，但替代模型必须使用所选节点的协议。Streaming 不提供自动转码、麦克风或实时字幕界面。语言留空使用当前音频已声明语言，也可接参数线。附加参数默认为空，仅显式提供时发送，不能覆盖模型、输入、认证、路由或核心协议字段。

每个节点分别配置连接与密钥，不选择全局 Profile、不读取环境变量、不继承其他节点的 Key。密码框留空保留已保存版本，输入新值在统一保存时替换；清除须显式操作。缺自身密钥时不能运行，服务环境里即使存在同名变量也不会备用。复制、粘贴及导入导出剥离本机凭据引用，目标节点需要重新填写 Key。

主页[全局设置](global_settings.md)可以设置新节点默认连接、模型、地域及 Key。只有通过添加菜单创建的节点复制默认值；保存时将创建时捕获的默认 Key 版本物化为本节点独立凭据。已有节点及已排队任务不随全局值变化，复制或导入也不自动取得默认 Key。

## 保存与快照

密钥通过 `PUT /api/v1/projects/{pid}/workflow` 的只写 `credential_updates` 提交，有更新时附稳定 `request_id`。`set` 替换、`clear` 清除当前绑定，`use_default` 为新节点复制指定不可变默认版本；相同请求重试不反复轮换。校验只接收图，允许无密钥草稿；运行前要求自身凭据可用。

待提交密码仅存在当前编辑会话私有缓冲，不进入图、撤销、Pinia 可序列化状态、本地存储、导出或测量克隆。仅改密钥也触发未保存保护并阻止运行；失败保留输入供重试，成功清空，切换语言、尺寸与视口不丢输入。删除节点或明确放弃时清理，撤销不恢复明文。

后端使用标准 [Fernet 认证加密](https://cryptography.io/en/latest/fernet/) 保存不可变凭据版本，图和运行快照只存不透明引用，归属绑定项目、节点与 Provider 类型。每次替换创建新版本；排队、批次及重试沿用原图的地址、设置和 Key 版本，后来修改当前节点不影响已提交任务。不可解密或归属错误时明确失败，不换用其他来源。

主密钥与密文在数据根 `.credentials/` 的 `master.key`、`store.check`、`versions/` 下，工作流导出不含它们。备份须同时保护原始主密钥和密文；若整个数据目录泄露，此同机加密不提供额外隔离。缺失或损坏时不会重建密钥冒充旧数据可用。删除项目不清理全局密文，暂未提供主密钥轮换与历史凭据垃圾回收。

目录 `1.11` 的 `presentation.inline_connection_input` 声明 Provider、地址、超时、可选地域、凭据引用及数据处理信息；没有模式、环境变量或 Profile 角色。前端和通用执行器按声明工作，不维护节点类型白名单。连接及凭据不开放参数线。

## 旧连接移除

全局服务连接界面和 `/api/v1/provider-profiles` CRUD 已移除；`provider_profiles.json` 不再读取。旧 Filetrans 配置中的 `provider_profile_id`、`connection_mode`、`api_key_env` 不再接受，返回 `LEGACY_CONNECTION_UNSUPPORTED` 或带相同重建说明的字段校验错误。包括以前使用内联模式但仍含这些兼容字段的节点，均需删除后重新添加并填写本节点连接与密钥。

不自动迁移、删除或改写现有数据。历史运行、批次和产物继续按原归属查看/下载；旧 `provider_profiles_snapshot` 只作原始历史元数据，不用于执行、重试、鉴权或推断发送目标。新图提交不生成该字段，历史复制仍可保留原始元数据。旧连接模式的批次不能借新配置重试，需用新图创建运行。

## 传输与取消

Filetrans 的平台控制请求、OSS 上传及结果下载隔离认证与 Cookie；后两者不携带平台 Bearer。总超时覆盖上传凭证到结果下载，取消须等待本地传输与文件读取回收。已知任务 ID 时只尝试一次有界取消；平台仅允许 `PENDING` 取消，`RUNNING` 可能继续或计费。临时文件约 48 小时后由平台清理，没有提前删除接口，不把临时上传当作生产高并发存储。

Streaming 使用完整 WSS 端点，明文 WS 仅限本机回环；拒绝 URL 中的认证、查询和片段，不跟随重定向。完整任务结束后才发布最终句子，真实毫秒转秒，重复最终句子去重，冲突或提前断线失败。取消/超时关闭连接并回收收发与读取；不自动重连/重发，也不能撤回已发送音频或保证远端停止/退款。不套用 Filetrans 的临时文件保留时长。

统一转写保留真实时间、字词及说话人信息；缺时间戳不伪造，TXT 可以导出无时间文本，字幕仍要求完整时间范围。失败不回退 Mock。密钥、认证头、签名 URL 和原始服务错误不进入日志、响应或产物。

协议来源及验收分别见 [Filetrans 规格](../spec/cloud-asr-qwen.md)、[Streaming 规格](../spec/cloud-asr-qwen-streaming.md)与[移除旧连接](../spec/node-connections-only.md)。验证使用 Windows 隔离模拟平台与合成音频，不能等同于真实账号、质量、计费或其他系统验收。
