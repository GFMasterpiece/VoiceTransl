# 连接、模型与云端处理

服务连接和模型配置是独立节点。LLM 翻译、Qwen Filetrans 与 Qwen Streaming 处理节点从端口取得它们，不再内嵌连接、模型、密钥、上下文或执行参数。当前契约见[普通文本上下文规格](../spec/plain-text-context.md)。

## 搭建方式

1. 在音频输入节点上传或选择资源，上传时提供源语言。
2. 添加“服务连接”，选择协议，填写地址、API Key 和可选地域。
3. 添加“模型配置”，连接服务连接，填写模型名；可显式提供 JSON 请求参数，也可连接 JSON 值/合并节点。
4. 将模型输出接到对应处理节点。上下文端口直接接字符串值或多输入拼接结果，语言、要求、背景和术语可以写成普通文本；总超时、分批等来自独立执行参数。
5. 处理结果连接文本预览或文本输出，保存图后运行。一份资源走单运行，多份资源走冻结快照批次。

同一连接可以通过模型节点供多个处理节点使用；同一模型、上下文或执行参数也可分支连接。共享必须通过连线，不按相同地址、名称或 Key 自动合并。

| 连接协议 | 地址填写示例 | 模型示例 | 处理节点 |
| --- | --- | --- | --- |
| `openai_chat` | `https://example.com/v1`，执行时追加 `/chat/completions` | 服务实际支持的模型名 | LLM 翻译 |
| `qwen_filetrans` | `https://maas.qianwenaiapi.com/api/v1` | `qwen-audio-3.1-asr-flash-filetrans` | Qwen 语音识别 |
| `qwen_streaming` | `wss://maas.qianwenaiapi.com/api-ws/v1/inference` | `qwen-audio-3.0-asr-flash-streaming` | Qwen 流式识别 |

示例不是模型白名单，也不自动替换用户地址或模型。地域明确为可选，只作人工声明，不决定路由或证明实际处理区域。地址必须含 http(s):// 或协议适用的 ws(s)://，裸域名不能作为完整端点。端点不得包含 URL 认证、查询或片段；Streaming 的明文 WS 仅允许本机回环。

识别语言取当前音频声明；翻译沿用上游当前文本及其语言作为输入元数据，输出语言由有效模型响应声明。上传源语言候选来自后端且可搜索，也允许自定义代码。模型请求参数默认空，只有显式提供时发送，不能覆盖认证、核心输入、路由或协议结构。

## 密钥与默认模板

密钥归服务连接实例，绑定项目、连接节点 ID 及凭据类型。处理节点仅沿模型绑定使用这一不可变版本；不能从全局 Profile、环境变量或其他未连接节点取得 Key。

密码留空保留当前版本，输入新值在统一保存图时更新，清除须显式操作。复制、剪切粘贴和导入导出剥离引用及私有缓冲，目标连接需重新填写；单纯把同一连接输出再接给一个消费者，不复制或轮换 Key。

[全局设置](global_settings.md)只提供新建配置节点的模板。新连接捕获默认 Key 的不可变版本，首次保存时物化为它自己的凭据；已有节点和任务不补读默认值，复制或导入也不自动取得默认 Key。

密钥通过工作流 PUT 的只写 `credential_updates` 提交，有更新时使用稳定 `request_id`。失败保留当前页面私有输入，成功清空；密码不进入图、撤销、Pinia 可序列化状态、本地存储或测量克隆。仅改密码仍使草稿变脏并阻止误运行旧配置。

后端使用标准 Fernet 加密。数据根 `.credentials/` 的主密钥和密文应一起备份；此同机存储不抵御整个数据根泄露。运行图、模型端口、checkpoint 和响应只包含公开连接描述与不透明引用，真实 Key 仅在适配器边界解密；恢复检查归属和冻结配置，不以相同 URL 替代验证。当前未提供主密钥轮换或历史凭据垃圾回收。

## 运行边界

图、运行、批次和默认设置为 `3.0`，能力目录为 `1.17`。新存储不读取旧图、旧运行或旧模板；旧文件留盘但不迁移、不执行。项目与音频资源仍可使用。不得为旧内嵌连接字段增加后备读取。

提交及重试使用固定图、模型、上下文和 Key 版本，不回读最新设置。重跑会重新物化必要纯配置祖先，并用其指纹检验处理缓存。修改共享连接后从某个处理节点重跑，不必从连接根执行全部分支；必要处理祖先已失效时仍须前移起点。

两种 Qwen 的普通上下文均按一条 user/input_text 发送，空值省略，超过 400 字符在网络调用前拒绝。Filetrans 隔离平台控制、OSS 上传和结果下载的认证及 Cookie。已知任务 ID 时本地取消只尝试一次有界远端取消；平台仅允许 PENDING 取消。Streaming 按真实音频速率发送 PCM16 单声道 WAV，读文件头采样率，完成后才发布最终文本；不自动转码、不提供麦克风或实时字幕界面，也不重连重发。

超时来自执行参数，覆盖整次处理；取消和关闭须回收请求、收发与文件读取。不能保证撤回远端已处理内容。真实时间戳缺失时不补造，TXT 可导出无时间文本，字幕格式仍要求真实时间轴。错误不回退 Mock，Key、签名 URL 和原始服务错误不进入响应或日志。协议细节见 [Filetrans](../spec/cloud-asr-qwen.md)、[Streaming](../spec/cloud-asr-qwen-streaming.md)和[翻译](translation_providers.md)。
