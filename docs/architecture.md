# 当前 Web 架构

当前维护 `backend/` 与 `frontend/`。桌面端、旧本地模型及固定阶段执行器不作为开发入口。资源与 API 见[多音频契约](voicetransl_multi_audio_project.md)，交互见[前端工作流](frontend_workflow.md)，进度见[线路图](roadmap.md)。

## 分层

- FastAPI 路由负责请求、修订/幂等、归属及错误映射；应用层组织运行、批次、纯配置求值、检查点和取消。
- 领域层拥有图、类型、字段、协议绑定和注册契约；`nodes/` 模块声明各节点并实现构造或处理，适配器封装云端协议。
- 文件系统是唯一数据源，项目目录隔离资源，状态 JSON 原子发布；没有数据库、Redis、Celery 或外部 Worker。
- Vue 编辑器消费后端目录，不维护第二份节点、端口、模型或格式名单。REST 和文件是运行状态来源，界面通过轮询更新；云适配器的 WebSocket 与浏览器通知无关。

## 节点职责与配置图

默认图仍是 `audio_input -> audio_output`，不执行识别、翻译或转码。云处理采用可组合配置：

| 类别 | 节点 | 契约 |
| --- | --- | --- |
| 资源 | 音频输入 | 绑定当前/指定音频或有序资源清单，每次实际运行仍输出一份 audio |
| 连接/模型 | 服务连接、模型配置 | 地址/协议/凭据归连接；模型名及显式请求参数归模型，通过端口复用 |
| 普通值 | 文本、整数、数字、布尔、JSON、音频信息 | 命名 typed 输出，文本支持多行，JSON 只接受对象 |
| 组合 | 文本拼接、JSON 合并 | 二元、固定左右顺序；JSON 默认冲突报错，可显式选择左右值 |
| 上下文 | 翻译上下文、识别上下文 | 前者组装语言/背景/要求/词表，后者当前只表达识别语言 |
| 执行参数 | 翻译参数、识别参数 | 总超时及适用的分批、邻接片段、重试，与模型请求参数分开 |
| 处理 | Qwen Filetrans、Qwen Streaming、LLM 翻译 | config 为空，通过 typed 输入消费模型、上下文及执行参数 |
| 调试 | Mock 预处理、Mock 识别 | 仅示例；添加入口需浏览器调试模式，当前无 Mock 默认模板 |
| 终端 | 音频/文本预览、音频/文本导出 | 消费直接上游，真实输出格式来自后端声明 |

一个配置输出可连接多个消费者。复用只由连线发生，不按相同地址或内容自动合并。连接/模型绑定携带公开不可变描述和不透明 credential_ref，不携带真实 Key。上下文和参数使用版本化不可变值，JSON 投影返回独立对象，避免消费者修改公共输入。

源语言的空值保留继承语义：ASR 在每份音频执行时读取该音频语言，翻译在每个处理节点读取直接上游当前文本语言；批次不能用首份音频补齐全部上下文。翻译目标在实际求值时必填，模型、协议及静态配置在云调用前检查。

文本拼接默认两个换行；JSON 只做顶层合并。组合后仍执行文本长度、JSON 深度/大小和消费端语义校验，不截断或按敏感词误杀普通术语。详见[可组合配置规格](../spec/composable-node-configuration.md)。

## 图与注册契约

图恰好一个音频资源源、至少一个终端；配置根不计入资源源数量。允许分支、串联、汇合及输入直通预览/导出，节点和边各最多 64 个。拒绝环、孤岛、未知类型、无效端口和危险配置；所有节点均须能到达终端。

`domain/node_contracts.py` 定义契约，`domain/node_registry_core.py` 统一校验与派生，`domain/node_registry.py` 组合内置模块。`register_type` 声明类型、父类型、能力、codec及展示颜色；`register_port` 声明稳定端口 ID 与逻辑 type_id、能力要求；`register_node` 绑定字段、端口、必填输入、类别和执行入口。端口身份与数据类型分开，实际音频子类型可通过父类型/能力满足 audio，无需客户端类型名单。

`required_input_ports` 逐名声明，每个必填口恰一条兼容入边，可选口零或一条，一个输出可分支。同节点对可连接不同命名端口。失败上游即使接在可选口也会阻断消费者；未接可选口才采用节点声明默认值。

字段通过 `input_port/input_type_id` 声明参数绑定，支持标量和 JSON 对象。接线保留手填后备，执行时投影、校验实际配置并使用节点副本，记录参数来源和有效值，不改写冻结图。资源和认证不开放参数线；多行输入用通用 widget 声明。

`evaluation_kind` 区分 configuration 与 processing；`can_start_without_inputs` 允许带可选输入的构造节点独立起步。普通运行、预检及重跑共用纯配置求值，不能按内置节点类型分支或把静态/音频相关求值写成两套。

执行器读取 `NodeExecutionContext` 的命名 `NodeData`，返回 `NodeResult`，输入和输出均按注册类型验证。业务错误为稳定 NodeExecutionError；取消先清理再报告。新增既有数据类型的节点无需改通用调度器或前端名单，用户不能从 API 注册任意 Python 代码。

## 文本与云适配器

Transcript 用 `metadata.current_text={version:"1",field:"source_text"|"normalized_text"|"translated_text",language:"..."}` 声明当前文本。无声明的识别文本按原文读取，非法声明或缺当前内容失败。翻译复制输入、更新译文及当前语言，保留原文、ID、时间轴、说话人和元数据；连续翻译使用上一步译文。预览、导出和 checkpoint 共用领域函数，不按前驱节点类型猜内容。

服务协议与操作能力由单一注册源声明。同协议的新模型自由配置，新协议显式新增适配器；不查询成功就不能声称已发现全部支持模型。默认不发附加参数，禁止覆盖核心输入、认证、路由或结构协议，未知能力不回退 Mock。

Filetrans 使用隔离认证的控制请求、临时上传和结果下载；Streaming 使用 run-task/二进制/result/finish-task 协议，仅支持文件 PCM16 单声道 WAV，自动读采样率、限速发送、只汇总最终句子，不重连重发或自动转码。LLM 使用 Chat Completions 结构化返回，有限分块和明确条件重试。所有适配器保留真实时间信息，不补造时间戳。

总超时来自对应执行参数。取消、超时和服务关闭必须回收本地请求、文件读取及收发，不只停止等待。Filetrans 已有任务仅作一次有界远端取消，Streaming 关闭连接；无法保证撤回远端已处理内容。详见[节点连接](node_connections.md)和[翻译](translation_providers.md)。

## 持久化与版本

| 文档 | 当前版本/位置 |
| --- | --- |
| 项目、音频、Transcript | schema `1.0`，沿用资源目录 |
| 项目公共图 | schema `2.0`，`workflow-v2.json` |
| 主音频运行 | schema `2.0`，项目根 `workflow-runs-v2/{rid}/` |
| 其他音频运行 | schema `2.0`，`audios/{aid}/workflow-runs-v2/{rid}/` |
| 批次 | schema `2.0`，`batches-v2/{bid}.json` |
| 全局设置 | schema `2.0`，数据根 `settings-v2.json` |
| 能力目录 | API 外层 `1.0`，独立 workflow capability `1.16` |

仅接受各文档当前版本和对应嵌套快照，不将业务 JSON 的 schema_version 当文档。旧图、旧运行、旧批次和旧模板不读取、不迁移、不转换，也不删文件；已有项目没有新图时提供当前音频直通默认图。资源格式未变，音频不需重传。旧目录和处理节点内嵌字段明确拒绝，前后端须使用同一新版契约。

布局与执行版本分开，位置、尺寸及显示信息不改变语义修订。图按项目共享，每次运行创建新 ID 和完整不可变快照；状态、节点产物、preview、checkpoint 按运行隔离，不能覆盖人工结果或源文件。路径使用项目相对 POSIX 形式，校验归属、摘要及目录穿越，拒绝危险链接。

## 密钥、默认值与并发

真实 Key 通过只写更新及稳定 request_id 保存，Fernet 密文版本先落盘，再原子发布图；图、端口、checkpoint、错误及日志只有安全描述和引用。密钥归连接 owner，恢复须校验 owner/协议/版本与冻结图，调用边界才解密；不恢复 Profile、环境变量备用或借用其他节点的隐式连接。

前端密码仅在私有缓冲，不能进入草稿、撤销、浏览器存储或测量克隆；复制/粘贴/导入导出清除引用。全局模板只影响菜单新建节点，默认 Key 在首次保存时按捕获版本物化成连接独享凭据，已有图及排队任务不补读。服务端并发、默认字段和私有版本令牌在 settings-v2 原子保存；浏览器语言和调试模式只为本地展示。详见[全局设置](global_settings.md)。

同音频不能并行两个任务，不同音频共用动态全局许可。任一音频运行、取消或预留排队时，删除项目返回 PROJECT_BUSY。服务关闭回收任务，启动扫描把新存储中的未结束记录标记 interrupted，不自动恢复云调用。

## 重跑与检查点

每个成功节点按实际类型显式 codec 发布有界 sidecar、文件描述、摘要及递归指纹；子类型不自动继承 codec。指纹包含类型/执行版本、实际及后备配置、完整依赖映射、上游指纹/摘要与源音频实际身份，不含布局或输出存储路径。

重跑使用当前保存图和同音频明确终态来源，强制选中节点及全部后代执行。必要纯配置祖先重新求值；必要处理祖先验证、复制 checkpoint，其他节点 skipped。配置变化进入依赖指纹，不能复用旧语义；处理祖先失效时要求前移起点，不自动扩大云调用范围。

复用文件物理复制到新运行，禁止硬/软链接回旧运行；重新核对哈希，创建新 artifact ID 和地址。排队启动再次检查，来源丢失/损坏不自动补算。预检不调用模型，提交锁内再次规划并处理幂等；普通运行仍全图执行。批次只支持单项独立重跑，保留原编号，不改原批次。见[重跑规格](../spec/node-rerun-reuse.md)。

## 文件夹与批次

浏览器收集文件和目录，仅向服务端上传文件及受控来源元数据，不把客户端目录当服务端任意路径。音频输入保存有序唯一的资源 ID 清单；一项用单运行，多项由服务端固定图/清单逐项调度，前端不循环提交运行。原有上传和管理操作不自动执行工作流。

批次预留所有排队音频，固定数量 dispatcher 共用全局许可，不为所有文件各建等待任务。一个项目最多一个活动批次，单项失败不停止其他文件。取消停止派发、回收活动任务；明确重试创建新批次/运行，使用原快照与固定序号。

BatchItem.sequence 按输入 index+1 固定，重试保留间隙；输出 exact 或 prefix_sequence 共用命名逻辑，独立运行编号 1。artifact 与 ZIP 保留实际完整名称/扩展名，128 字符前缀不截断。ZIP 按来源、文件及节点隔离，附 manifest；下载后清理临时文件。详见[批次规格](../spec/batch-processing.md)。

## 界面与验证

节点表单只保留标签、控件、短状态、错误和实际结果；不重复密钥、取消或数据处理说明。语言候选来自后端，支持自定义代码，搜索词不入图。文本中英展示通过集中消息，机器标识不翻译，未知扩展标签保留原文。切语言不重载图、不丢密码或 File。

测试和交付要求见 [AGENTS.md](../AGENTS.md)。未测平台和真实账号效果不能描述为已验收。
