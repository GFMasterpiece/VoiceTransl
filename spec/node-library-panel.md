# 节点库面板

状态：Implemented · 2026-11-10

## 体验与入口

参考 ComfyUI 的节点搜索布局，保留本项目配色。桌面显示顶部搜索和输入/输出类型筛选、左侧分类、中间节点列表、右侧节点示意卡及端口/字段详情。面板尺寸受视口约束，各栏独立滚动；窄屏可切换列表与详情，分类仍可操作，隐藏内容不参与焦点。

工具栏“添加节点”和画布空白右键打开同一面板，分别记录打开时的画布中心或点击位置；浏览不修改图、选择、视口或撤销历史，添加成功才使用记录的世界坐标创建一次并关闭。节点右键保留原有编辑菜单，不混入粘贴或添加列表。

## 目录与交互

- 类别、节点名称/类型、端口、数据类型、字段和默认项来自后端目录及通用 registry；Mock 仍按调试偏好隐藏，不生成市场、推荐或收藏数据。
- 搜索支持中文、英文和节点类型，以及目录中的分类、字段和端口名称；与分类和输入/输出类型筛选共同生效。类型筛选按实际 typeId 匹配，不自动连线。
- 悬停、焦点及方向键只更新当前候选和右侧详情；单击或 Enter 添加。触屏提供独立详情入口，查看和返回保留搜索与筛选。
- 实例/源/节点数量上限由现有目录裁决，受限节点仍可查看，但不可添加，显示简短原因。未知目录和能力加载失败沿用原错误处理，不伪造节点名单。
- 示意卡仅使用目录声明，展示端口方向、类型、必填属性及字段；不读取当前节点、全局默认 Key 或密码缓冲，不实例化处理器，不上传、保存或运行。隐藏凭据/资源引用字段。

## 焦点与保护

打开时聚焦搜索框；上下键浏览候选、Enter 添加，Escape 关闭并恢复入口焦点，Tab 留在弹窗中。输入法组合期间不因 Enter/Escape 误添加或关闭。打开/关闭、切换详情和窄屏隐藏均遵守焦点及 inert 约束。

沿用上传、保存、运行及其他弹窗的编辑保护；打开后状态变为锁定也不能继续添加。草稿、待传文件、密码和当前选择不能因关闭面板丢失，组件卸载须清理监听及焦点保护。

## 兼容与验收

仅变更前端浏览和添加入口。图/运行/批次/默认设置仍为 4.0，目录仍为 1.18；不改已有节点、快照、执行、凭据或后端数据。

验收包括两入口坐标、搜索/分类/类型组合、跨语言与扩展元数据、候选/详情无创建副作用、单次添加、上限和编辑锁、调试过滤、键盘/IME/焦点恢复及窄屏详情。前端全量测试及构建通过，实际验证方式和未实测部分在完成后记录。
