# 节点参数与连线输入统一

> 状态：Implemented（2026-11-06，Windows 本机验收）。适用于节点模块化和命名多端口之后的当前 Web 工作流。

## 范围

- 节点声明允许连线的配置字段，前端按声明展示参数端口，用户可直接填写或通过上游值节点提供参数。
- 首批可连线字段为 Mock ASR 的 `language`、音频与文本输出的 `filename_stem`、文本输出的 `format`。固定 Mock `provider` 与输入资源 `audio_id` 不开放参数连线。
- 基础节点为 `string_value`、`integer_value`、`number_value`、`boolean_value`，各自保存 `{value: ...}` 并输出对应逻辑类型。字符串与已有的 `text` 文件产物类型分离。
- 一个运行仍绑定一个项目音频；参数来源与音频资源来源分开建模，不增加多音频源、真实模型、表达式、任意代码、缓存重跑或子图功能。

## 单一契约来源

- capability API 顶层 schema 仍为 `1.0`，工作流目录版本升为 `1.5`；版本值在 API 内只维护一处。前端显式兼容已有 `1.2/1.3/1.4` 协议，拒绝未知版本。
- `CapabilityField.input_port: string|null` 表示该字段是否允许指定的输入端口覆盖。该端口必须在节点 `input_ports` 中、不得在 `required_input_ports` 中；同一节点的字段名及绑定端口各自唯一。绑定端口的逻辑类型必须满足字段表示类型，注册和目录解析都拒绝不一致契约。
- 首批端口映射为 `language → string`、`filename_stem → string`、`text_format → string`，字段与端口名称可以不同。新增同一协议的节点/字段通过声明和注册接入，不改调度器或前端类型名单。
- 节点新增 `is_parameter_source: boolean`；已有 `is_source` 继续表示唯一音频资源源。参数根不得同时标为音频源，不接受图输入，不应使用资源选择元数据冒充音频资源。
- `1.5` 目录中的每个节点必须显式提供 `is_parameter_source`，每个配置字段必须提供 `input_port`（不可连线时为 `null`）；命名必填输入继续采用已有严格数组校验。旧版本缺失的新字段明确解释为无参数绑定、非参数根。
- `integer` 是 `number` 的逻辑子类型；整数和数字校验均排除布尔值，数字必须有限。字段值在执行前仍通过自身完整配置校验，不因端口类型兼容而绕过枚举、语言和文件名安全规则。
- `select` 延续现有目录协议，仅支持非空字符串选项列表；整数、数字和布尔参数使用各自字段类型，不在本轮扩展枚举值协议。

## 图与前端行为

- 图仍要求恰好一个音频资源源、至少一个终端，并限制节点和边数、拒绝环与孤岛；参数根不计入资源源数量。
- 可达性从资源源和显式参数根的并集计算；其他零输入节点不能自行成为合法根。每个节点仍须能到达终端。参数根即使只服务于某个配置端口，也有正常依赖、失败和取消状态。
- 参数端口零或一条入边；连接完成后只覆盖本次执行值，不删除、重置或改写节点的手填 `config`。手填配置仍须合法，保证断线后恢复的后备值可用；不把未完成的数字或 JSON 输入静默修复成默认值。
- 已连接字段隐藏对应手填字段整行，取消控件、标签与占位；端口保留，上游来源与覆盖说明放在端口悬停及辅助文本中。断线后恢复原控件和原值并可编辑。切换语言、选择节点、取消拖线或重新连线不丢失后备值，也不影响其他端口。
- 可见字段参与节点内容测量及最小尺寸计算，隐藏字段不保留设置区空白；仅隐藏控件不自动改写用户显式尺寸、配置或运行快照。所有字段均被连线覆盖时，节点保留标题及端口，不以重复节点名称替代设置。
- 参数端口名称由字段绑定及其展示标签派生，类型由端口目录提供，区分同为字符串的语言、文件名与格式输入；未知扩展不需要前端增加节点或端口分支。
- 数据端口、参数端口使用同一条边协议、类型目录和几何计算；资源绑定、草稿离开保护、活动运行锁定等行为保留。客户端根据目录提供即时提示，后端为最终权威。

## 执行与持久化

- 排队快照仍保存原手填配置及图连线。新运行排队时从自身快照冻结每个字段的来源，不在执行时查询后来修改的项目图。
- 取得上游值后，创建配置副本并覆盖实际绑定字段，对最终配置完整校验/规范化，再将节点副本交给执行器；不得修改 `run.workflow` 或原有节点记录 `config`。
- 上游失败或缺少结果时依赖阻断；候选值类型、枚举、语言、文件名等非法时节点明确失败，不调用执行器，不回退后备值，不发布该节点产物。无关分支仍可继续。
- 节点记录新增可空 `parameter_sources` 和 `effective_config`。来源按字段保存：手填为 `{kind: "config"}`；连线为 `{kind: "connection", edge_id, source_node_id, source_port, target_port}`。结构通过模型校验，来源不重复保存展示名称或参数值。
- `effective_config` 尚未解析时为 `null`；解析成功后记录最终执行配置；候选配置非法时可以记录候选值，失败状态明确表明未执行。被阻断或提前取消的节点不得伪造已解析参数。
- 日志/运行详情按所选运行展示已记录的来源与实际参数，按纯文本渲染；历史缺失字段显示“未记录”，排队尚未解析显示“尚未解析”，不能用当前默认配置推测旧执行值。
- 项目、工作流、运行及嵌套快照持久化 schema 仍为 `1.0`；新元数据为可选字段。旧图、旧记录、旧下载和默认直通继续可用；不迁移、不补写旧文件，不改变严格同版本读取规则。
- 暂被连线覆盖的手填配置变更仍计入执行语义摘要，保持既有保存/冲突规则。密钥与认证信息不得作为可连线配置或写入运行记录；未来真实 Provider 仍由服务端独立解析凭据。

## 验收

1. 字符串值节点覆盖 Mock ASR 语言，输出实际采用上游语言；手填语言在配置与不可变快照中保留，断线重跑恢复手填值。
2. 输出文件名/格式连线可运行，非法枚举、目录穿越或 Windows 保留名称在发布前失败；不能靠手填合法值掩盖非法上游值。
3. 基础值精确校验类型，整数能供给数字字段，布尔值不冒充数字，拒绝 NaN/Infinity；测试扩展字段与端口异名，无需修改通用调度器或前端节点名单。
4. 参数与音频数据汇合、缺少必填/重复连接、参数根失败及独立分支隔离、排队后编辑图、活动运行取消与资源清理均回归。
5. 前端接线后隐藏对应手填字段行并保留后备值，断线恢复控件及原值，取消、重连和语言切换保留状态；节点尺寸反映可见字段且保留用户显式尺寸，隐藏的无效后备值仍阻止保存。来源/实际参数按运行隔离，旧记录缺失不推测，内容安全渲染。
6. 后端全量 pytest/Ruff、前端全量测试及构建通过；Windows 浏览器验证实际拖线、保存、运行、下载和重新载入。未实测平台明确注明。

验收记录：后端全量 219 passed、2 skipped（Windows 符号链接权限相关既有跳过），Ruff 检查及格式检查通过；前端 252 项测试及生产构建通过。独立临时数据目录和端口上的 Windows Edge 验证了实际反向拖入参数线、取消拖线、中英切换、控件禁用及断线恢复、参数覆盖运行、SRT/音频下载、非法文件名失败与独立分支成功、历史快照不变和刷新重载。节点设置未超出内容区，参数端口显示用途及类型，浏览器异常为零；未改动已有运行数据。Linux 本轮未实测。

交互调整验收（2026-11-06）：已连接字段由禁用显示改为整行隐藏，保留组件的原始输入缓冲和配置后备值。前端全量 253 项测试及构建通过；Windows Edge 验证接线隐藏、断线恢复、重连/取消、中英切换、最小高度收缩及显式尺寸保留，运行、下载、历史重载继续正常，浏览器异常为零。后端契约和持久化格式未改变。
