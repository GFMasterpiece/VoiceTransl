# 节点参数与连线输入

状态：**Implemented**。当前构造节点和新图版本见[可组合配置规格](composable-node-configuration.md)。

## 契约

- 能力目录1.16发布字段input_port与input_type_id，可空表示不可接线。绑定必须唯一、存在于该节点输入口、为可选且与字段逻辑类型兼容，不按字段名或节点类型猜测。
- 标量节点输出string/integer/number/boolean，JSON值输出json_object；text仍为文件产物。字符串多行编辑由widget声明，语言搜索由suggestion_source声明。
- 输出名称/格式及配置构造节点的语言、文本、JSON、模型名和执行参数可按声明接线。处理节点不再保留内嵌字段，其typed model/context/options是完整输入包，不投影回config。
- 服务连接的endpoint、协议、地域、认证、资源绑定不自动开放参数线，真实Key只写独立存储。模型请求JSON须按实际协议再次校验，不允许覆盖认证/核心输入。
- 构造节点以evaluation_kind=configuration声明纯求值，can_start_without_inputs允许有可选输入的节点自行起步；已有接线仍须等待依赖完成。唯一音频源与配置根分开计算。

## 手填与执行

手填始终是合法后备，接线不改写图；连线后整行控件隐藏，断线恢复原值和输入缓冲。隐藏字段的无效后备仍阻止保存。执行把实际入参投影到节点副本，完整校验/规范化并记录parameter_sources/effective_config，不改冻结图。

输入类型精确验证：整数可以满足数字，布尔不冒充整数，拒绝NaN/Infinity。JSON只接受有界对象，规范化后给消费者独立对象，合并后仍受限制。词表中的password等业务词合法，认证由专门角色隔离。

参数边与媒体边共用依赖关系，一个输出可分支，每个输入最多一条。可选端口未接采用后备；接了失败上游仍阻断消费者。端口名与字段名可不同，不默认取首个口。

## 快照与重跑

图/运行为2.0，仅读取新命名空间，不兼容或迁移旧图。排队使用保存时图和Key版本；全局默认仅在新节点创建时捕获，执行不读取。位置、尺寸和边ID不改变语义；后备配置、接线映射和实际值均参与指纹。

重跑重新物化必要纯配置祖先，按新指纹验证必要处理缓存；源或处理祖先失效时要求前移，不自动调用模型。导出和预览继续读取直接上游当前文本。

## 验收

- 文本和JSON多级组合、手填/接线切换、合法后备保留、组合后超限和非法实际值拒绝。
- 字段/端口异名、自定义节点及新模型不要求修改通用调度器或前端名单。
- 参数根/音频源汇合、必填/重复/失败依赖、分支隔离、排队冻结、取消和资源回收。
- 中英切换、JSON及多行文本测量、接线隐藏/断线恢复、撤销及显式尺寸保留。
- 后端全量/Ruff、前端全量/构建和Windows隔离Edge。当前本轮记录见[可组合配置规格](composable-node-configuration.md)。
