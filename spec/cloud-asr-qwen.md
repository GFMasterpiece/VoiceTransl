# Qwen 录音文件识别节点

状态：**Implemented**（2026-11-07）。独立节点、连接管理、快照及模拟服务验收已完成；未使用真实账号，不把接口与模拟测试等同于付费服务或质量验收。

## 范围与协议来源

新增独立 `qwen_asr` 节点，保留原 `asr` Mock 节点及默认音频直通图。输入仍为一份音频，输出统一 `transcript`，直接衔接文本预览、TXT/SRT/VTT/LRC 导出及现有逐音频批次调度。

本轮采用用户指定平台的 Qwen-Audio-ASR-Filetrans REST 协议，推荐模型 `qwen-audio-3.1-asr-flash-filetrans`。模型名是自由配置，不维护永久白名单；只有沿用本适配器协议的新模型才能直接替换配置。Qwen3 的其他协议、实时识别、翻译、视频、本地模型和多服务商自动切换不在本轮范围。

核对的一手资料（2026-11-07）：

- [模型选型](https://platform.qianwenai.com/docs/developer-guides/speech/speech-to-text-models)。
- [Qwen-Audio-ASR-Filetrans HTTP](https://platform.qianwenai.com/docs/api-reference/speech-recognition/qwen-audio-asr-filetrans/http-api.md)。
- [临时上传](https://platform.qianwenai.com/docs/api-reference/more/upload-file-get-temporary-url.md)。
- [任务查询与取消](https://platform.qianwenai.com/docs/api-reference/more/async-task-management.md)。

默认 API base 为 `https://maas.qianwenaiapi.com/api/v1`，不是从其他平台示例推断的地址。可配置相同协议的服务地址；不据域名推断平台运营归属或宣称已验证其他服务商。

## 节点与服务连接

- 节点内配置连接 ID、自由模型名、语言及 JSON 附加参数。语言可由参数端口传入；空配置使用该次输入音频已有的源语言，不猜测语言。
- 连接引用不开放参数线。实际密钥不进入浏览器、图、Profile、运行快照、产物或日志，只在服务端执行时从 `api_key_env` 指定的环境变量读取。
- 复用全局 Provider Profile 的 ID、类型、显示名、base URL、环境变量名、地域、总超时和启用状态。前端增加连接管理弹窗，类型及默认值由节点目录声明派生，不维护第二份服务商名单。
- 目录增加 `presentation.provider_profile_input`，声明 `config_key`、`provider_type`、显示标签和创建连接的非密钥默认值。可选 `data_handling={temporary_upload_retention_hours,remote_cancel_pending_only}` 描述存储与取消边界；未声明时不猜测，历史不使用当前目录规则反推旧任务。Profile 选择项由后端按类型及启用状态派生；失效引用保留原 ID 并显示错误，不自动换成其他连接。
- 目录版本提升为 `1.7`，持久化 schema 仍为 `1.0`。前端保留旧目录支持；刷新连接及能力只更新缓存，不重新加载图，不丢失草稿、撤销、上传 File 或视口。
- 不增加每次运行的审批弹窗。界面说明云端传输目标与临时文件生命周期，实际处理继续由用户已有的运行操作启动。
- 附加参数默认 `{}`，不额外发送未配置的可选字段。参数只能进入协议的 `parameters`，不得覆盖模型、输入 URL、语言核心配置、认证、路由及密钥；限制 JSON 大小和复杂度。协议要求的 `parameters` 对象即使为空也必须发送。

## 快照与兼容

- `WorkflowSnapshot` 新增可空 `provider_profiles_snapshot`。普通运行提交时、批次创建时各冻结一次非密钥连接设置；通用冻结器依据注册声明识别依赖，不在调度器硬编码节点类型。
- 后续修改或禁用连接不改变已排队任务。批次子运行及失败重试只复制原快照，不能重新读取当前 Profile。实际环境变量的值不冻结，执行时读取冻结的变量名。
- 新提交检查连接存在、启用、类型及必要设置。缺密钥在执行阶段明确失败，不回退 Mock 或其他连接。包含云节点却缺连接快照的历史运行不能借最新连接继续执行。
- Profile 删除检查公共可编辑图及既有旧 Pipeline 引用；历史不可变快照不单独阻止删除。
- 旧图、旧运行、旧批次及旧 Job 继续可读，缺新字段保持未记录，读取不补写或迁移。Mock 的配置、示例结果及默认行为不变。

## 本地音频、HTTP 与结果

1. 按本次模型获取临时上传凭证：`GET /uploads?action=getPolicy&model=...`。
2. 以有界分块流向返回的 OSS 地址提交 multipart，`file` 为最后一项，认证仅使用上传表单凭证，不附带平台 Bearer。大小上限及凭证有效期使用实际返回值。
3. 单文件提交 `POST /services/audio/asr/transcription`，核心输入为 `input.file_urls=[oss_url]`，启用异步与 OSS 解析头。一个批次文件对应一次独立识别，不把 SDK 参数或 Qwen3 单数 `file_url` 套用到该协议。
4. 轮询 `GET /tasks/{task_id}`，同时校验总状态及文件子任务状态；成功后下载结果 JSON。结果下载不携带平台认证或上传凭证。
5. 将句子真实毫秒时间戳转换为秒。缺失时间戳保留成对 `null`，不能平均切分或伪造；合法字词、说话人信息作为非密钥结构化元数据保留。空结果、非法时间范围和坏响应明确失败。
6. 复用取消安全的转写产物发布，不调用会覆盖真实语言/元数据的 Mock 转换。TXT 可导出无时间戳文本；字幕格式沿用现有完整时间戳要求。

不把上传签名、临时凭证、结果签名 URL、认证头或任意服务端错误原文写入快照与产物。提交识别不做自动重试，避免响应丢失后重复创建付费任务；未知协议或能力不静默降级。

## 取消、超时与生命周期

总超时覆盖获取凭证、上传、提交、轮询和结果下载，不能每次轮询重新计时。HTTP 使用可取消异步传输，取消、超时和服务关闭必须等待本地请求、文件流和任务清理，然后释放忙碌边界。

已有任务 ID 时可以做一次有界的远端取消尝试；文档只保证 `PENDING` 可取消，`RUNNING` 不支持取消。因此不能承诺本地停止等同于远端停止、退款或立即删除云端音频。临时上传由平台约 48 小时自动清理，未找到提前删除接口；接口文档不建议此临时存储用于生产高并发，本轮面向当前本机开发工作流，不宣称具备生产对象存储能力。
