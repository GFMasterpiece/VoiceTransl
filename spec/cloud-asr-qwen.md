# Qwen 录音文件识别节点

> 历史里程碑：当前 LLM/ASR 服务与模型分别维护，ASR 上下文已移除，LLM 支持字段内编辑及参数连线；版本与现用契约见[服务分类与字段输入](service-families-field-inputs.md)。以下记录当时实现，不作为旧图兼容要求。

状态：**Implemented**（2026-11-08）。独立节点、每节点连接/密钥、快照及模拟服务验收已完成；未使用真实账号，不把接口与模拟测试等同于付费服务或质量验收。

## 范围与协议来源

新增独立 `qwen_asr` 节点，保留原 `asr` Mock 节点及默认音频直通图。输入仍为一份音频，输出统一 `transcript`，直接衔接文本预览、TXT/SRT/VTT/LRC 导出及现有逐音频批次调度。

本轮采用用户指定平台的 Qwen-Audio-ASR-Filetrans REST 协议，推荐模型 `qwen-audio-3.1-asr-flash-filetrans`。模型名是自由配置，不维护永久白名单；只有沿用本适配器协议的新模型才能直接替换配置。Qwen3 的其他协议、实时识别、翻译、视频、本地模型和多服务商自动切换不在本轮范围。

核对的一手资料（2026-11-07）：

- [模型选型](https://platform.qianwenai.com/docs/developer-guides/speech/speech-to-text-models)。
- [Qwen-Audio-ASR-Filetrans HTTP](https://platform.qianwenai.com/docs/api-reference/speech-recognition/qwen-audio-asr-filetrans/http-api.md)。
- [临时上传](https://platform.qianwenai.com/docs/api-reference/more/upload-file-get-temporary-url.md)。
- [任务查询与取消](https://platform.qianwenai.com/docs/api-reference/more/async-task-management.md)。

默认 API base 为 `https://maas.qianwenaiapi.com/api/v1`，不是从其他平台示例推断的地址。可配置相同协议的服务地址；不据域名推断平台运营归属或宣称已验证其他服务商。

## 节点连接与密钥

当前仅支持每节点独立连接，旧 Profile 和环境变量路径已按用户要求移除，完整取代此前兼容约定。具体移除与重建要求见[仅保留节点独立连接](node-connections-only.md)。

- 节点直接配置 `base_url`、`timeout_seconds`、可空 `region` 及 API Key，保留自由模型、语言及受限 JSON 附加参数。语言可接参数线，留空使用当前音频声明，不猜测语言。没有 Profile ID、连接模式或环境变量字段。
- 能力目录 `1.11`、持久化 `1.0`；`presentation.inline_connection_input` 只声明 Provider、地址、超时、可选地域及凭据引用角色，前端按声明渲染，通用执行器不判断 Qwen 类型。连接及密钥不开放参数线。
- 密钥仅经工作流保存的只写 `credential_updates` set/clear 提交，附稳定请求 ID；校验不接收密钥，无密钥草稿可以保存，运行前要求本节点有效凭据，不尝试环境变量或其他节点。
- 待保存密钥只在浏览器会话私有缓冲，不能进入图、撤销、Pinia 可序列化状态、浏览器存储或测量克隆。仅更改密码也参与草稿保护和运行禁用，成功清空、失败保留，切语言/视口/尺寸不丢失。
- 后端使用标准 Fernet 加密保存不可变版本，引用绑定项目、节点及 Provider。缺失、解密失败或归属不符明确报错，不能生成新主密钥冒充旧版本可用。主密钥与密文同机存放的备份边界见[节点连接](../docs/node_connections.md)。
- 凭据先落盘再原子发布图，同请求重试幂等；允许未引用密文，不能清理可能被历史使用的版本。复制/导入导出剥离引用，目标节点重新填写密钥。
- 附加参数默认空，只显式发送用户配置的可选字段，不能覆盖模型、输入、路由、认证及核心语言，保留 JSON 大小/深度限制。界面只展示字段、简短状态和必要错误；节点不重复展示发送目标，运行详情仅保留目标与文件数摘要，无额外说明段或运行审批。

## 快照与旧数据

- 单运行和批次提交冻结节点自身的非密钥连接及凭据版本，排队与重试沿用原图，不补读当前配置。适配器必需显式连接和 Key，不读取环境变量。
- 已删除全局连接 CRUD、配置文件加载、动态 Profile 选项、Profile 冻结及备用密钥机制。
- 含 `provider_profile_id`、`connection_mode` 或 `api_key_env` 的旧 Filetrans 节点在保存、执行和重试时明确拒绝，需删除后重新添加并填写本节点连接，包括以前含这些兼容字段的内联节点。
- 不迁移或删除现有数据。旧运行及产物保持可读；`provider_profiles_snapshot` 仅保留原始历史元数据，不参与执行或目标推断，新图提交不生成该字段。默认图与 Mock 行为不变。

## 本地音频、HTTP 与结果

1. 按本次模型获取临时上传凭证：`GET /uploads?action=getPolicy&model=...`。
2. 以有界分块流向返回的 OSS 地址提交 multipart，`file` 为最后一项，认证仅使用上传表单凭证，不附带平台 Bearer。大小上限及凭证有效期使用实际返回值。
3. 单文件提交 `POST /services/audio/asr/transcription`，核心输入为 `input.file_urls=[oss_url]`，启用异步与 OSS 解析头。一个批次文件对应一次独立识别，不把 SDK 参数或 Qwen3 单数 `file_url` 套用到该协议。
4. 轮询 `GET /tasks/{task_id}`，同时校验总状态及文件子任务状态；成功后下载结果 JSON。结果下载不携带平台认证或上传凭证。
5. 将句子真实毫秒时间戳转换为秒。缺失时间戳保留成对 `null`，不能平均切分或伪造；合法字词、说话人信息作为非密钥结构化元数据保留。空结果、非法时间范围和坏响应明确失败。
6. 复用取消安全的转写产物发布，不调用会覆盖真实语言/元数据的 Mock 转换。TXT 可导出无时间戳文本；字幕格式沿用现有完整时间戳要求。

不把上传签名、临时凭证、结果签名 URL、认证头或任意服务端错误原文写入快照与产物。提交识别不做自动重试，避免响应丢失后重复创建付费任务；未知协议或能力不静默降级。

## 取消、超时与生命周期

总超时覆盖获取凭证、上传、提交、轮询和结果下载，不能每次轮询重新计时。HTTP 使用可取消异步传输，取消、超时和服务关闭必须等待本地请求、文件流和任务清理，然后释放忙碌边界。

已有任务 ID 时可以做一次有界的远端取消尝试；文档只保证 `PENDING` 可取消，`RUNNING` 不支持取消。因此不能承诺本地停止等同于远端停止、退款或立即删除云端音频。临时上传由平台约 48 小时自动清理，未找到提前删除接口；接口文档不建议此临时存储用于生产高并发，本轮面向当前本机开发工作流，不宣称具备生产对象存储能力。

## 验收

- 假 HTTP 完整覆盖凭证、流式上传、单次提交、轮询、结果转换与产物输出；核实请求路径、头、复数 URL、必传空参数及认证隔离。
- 测试非推荐但同协议的模型，不靠模型白名单判断能力；模型/参数不兼容明确失败。
- 覆盖缺自身连接/密钥、引用归属不符、旧连接字段拒绝、恶意附加参数、坏响应、空文本、真实及缺失时间戳。
- 覆盖每个传输阶段取消、完整总超时、关闭清理及提交不重发；检查秘密和签名 URL 不落盘或泄漏到错误。
- 验证单运行/批次冻结、修改连接后的排队与重试仍使用旧设置；旧持久化文件读取保持原字节。
- 验证无全局连接入口/CRUD，能力刷新不损草稿/密码/上传/撤销，语言切换、参数线及现有批处理正常；环境变量即使有值也不备用。
- 后端全量测试、Ruff、前端全量测试和构建通过；隔离浏览器与假服务验证真实 UI 链路，不改用户运行数据。
- 没有真实凭据时只报告协议与模拟服务验证，不宣称真实账号、计费、长音频质量或其他操作系统已实测。
