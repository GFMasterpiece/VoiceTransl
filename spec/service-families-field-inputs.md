# 服务分类与字段旁连线

状态：Implemented · 2026-11-10

## 范围

ASR 不提供上下文输入。删除两种 Qwen 节点、适配器和协议入口中的 context，不通过附加 JSON 恢复。识别语言仍取当前音频声明，传输、时间戳、取消、批次和重跑语义保留。

LLM 与 ASR 分别配置服务及模型：`llm_service → llm_model → llm_translate`、`asr_service → asr_model → qwen_asr/qwen_asr_streaming`。连接和模型端口使用不同逻辑类型，在编辑、后端校验、执行和 checkpoint 恢复时拒绝跨类使用；不保留万能服务/模型节点别名。

LLM 服务当前使用 Chat Completions，填写 API base 和 Key；ASR 服务选择已实现的识别协议，填写对应 HTTP 或 WebSocket 地址和 Key。两者均移除未被适配器使用的地域字段。协议及可选请求参数从后端声明派生，不建立模型白名单。地址、协议及凭据仍由服务节点手填；密钥不开放普通字符串线。

各服务实例独立保存 Key；同族消费者可以显式共享连接，不按相同 URL 或值自动共享。凭据归属从节点声明取服务类型，不硬编码旧 service_connection；不可变版本、只写保存、私有输入缓冲、复制/导出剥离及排队冻结保持有效。

## 字段编辑与端口

- 仅后端声明 `input_port` 的字段展示左侧插口，标量、选项、JSON 及动态文本项使用同一组件。不按节点类型或字段名推测。
- 未接线时直接编辑节点内输入框。单行控件采用紧凑圆角布局，多行文本保留可读标题和编辑区域；沿用全局主题，不增加说明段落或编辑按钮。
- 连线后保留该字段的标签和插口，隐藏编辑控件并保留合法手填后备；断线恢复。插口本身不因已连线而禁用，可从输入反向起拖，取消不提前断旧线。
- 字段插口只出现在字段行左侧，不在节点头部重复。audio、transcript、各类模型等结构端口仍在头部。
- 复用现有双向拖线、命中、类型校验、撤销及复制粘贴。字段控件保留原生文本选择和输入操作，只有插口触发连线；锁定、失焦、Escape 和取消沿用现有编辑保护。

LLM 翻译节点直接提供多行 `config.context`，默认空。`context` 参数口可选，手填或接线覆盖；执行使用实际非空白字符串，保存可保留未完成草稿。可连接文本值或多输入拼接，不要求额外上下文节点。模型返回语言、当前文本及连续翻译语义保留。

## 布局与坐标

连线端点取实际字段插口的中心，通过 SVG 逆变换转换为节点本地坐标；不可用头部索引估计字段位置。首次测量前不把线错误画到头部。参数端口不再占头部排版行数。

缩放、平移、节点尺寸、多行控件、接线隐藏、错误、界面语言和动态项排序均须维持端点对齐。几何缓存不进入图、撤销或执行指纹，变化后按事件重测，不引入持续逐帧循环。内容测量克隆不可发布插口身份或保留明文 Key。

## 版本与持久化

图、运行、批次及默认设置升级 `4.0`，使用独立 v4 存储，能力目录为 `1.18`。用户已明确不保留旧图兼容；不读取、迁移或转换旧图、运行、批次和模板，旧文件原样留盘。项目、音频及 Transcript 保持 `1.0`，无需重传音频。

## 验收

- 两类服务/模型及默认模板分开，端口真实拒绝跨类；自定义兼容模型可配置，凭据不能跨族或跨 owner 借用。
- ASR 无 context 口、字段、适配器参数或网络消息；附加参数不能绕过。普通识别、语言、取消、字幕及批次仍可用。
- 翻译上下文手填即可运行；参数线覆盖，断线恢复原文，空实际值在外部请求前拒绝。重跑和排队快照使用各自固定值。
- 字段插口与控件行对齐，正反向拖线、接线隐藏、撤销/重做、复制/剪切/粘贴、动态输入增删排序正确；无头部重复插口。
- 真实浏览器验证不同缩放、节点尺寸、多行内容、中英及窄屏；实际连线端点与插口中心对齐，输入选择不触发拖线。
- 后端全量与 Ruff、前端全量与构建、隔离假 HTTP/WS 和 Edge 全链路、重启恢复通过。仅使用合成音频与假 Key，不调用付费服务，不修改用户运行数据。
