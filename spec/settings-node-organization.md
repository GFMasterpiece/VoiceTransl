# 设置分类与调试节点展示

状态：**Implemented**（2026-11-09，Windows 本机验收）。收敛全局设置导航、统一同类节点表单，并移除输入模式的重复入口。

## 范围和交互

- 全局设置一级导航按后端节点 `category` 分组，仅展示有默认设置的可见类别，保留“通用”；类别内选择具体节点类型，不随每个新节点增加一个顶级标签。未知类别保留后端名称，缺分类使用未分类。
- 两种 Qwen 同属语音识别。连接字段按目录角色展示地址、超时、可选地域，再显示 API Key；处理参数按后端有序字段展示模型、识别语言及附加参数。Streaming 不增加不存在的地域配置。
- 分类仅合并导航，不合并不同类型的配置或默认密钥；切类别、节点类型、语言及调试模式保留所有未保存字段和私有 Key，保存仍提交完整类型映射。保持固定窗口、独立内容滚动及简洁表单，不新增说明段落。
- 通用提供默认关闭的“调试模式”，作为当前浏览器的显示偏好立即生效，刷新恢复；不进入服务端设置、项目图、快照或摘要，也不改变服务端执行权限。
- Mock ASR 与 Mock 预处理由后端显式标记仅调试展示。关闭时隐藏添加菜单、右键搜索和默认设置入口；打开时恢复。已有、导入或粘贴图中的节点和历史保留，不删除、改写或隐藏其依赖关系。
- 音频输入仅通过已有模式下拉选择单项或多个文件/文件夹清单；移除下方重复的模式切换按钮。原文件选择、上传、清单及运行语义不变。

## 契约与兼容

- 能力目录升至 `1.15`，持久化 schema 保持 `1.0`。`NodeDefinition.debug_only` 缺省 false，由每个节点声明并由目录发布严格布尔值；前端不得按节点类型、名称或 Provider 推断调试属性。
- `NodeDefinition.settings_default_fields` 为有序声明，设置 API 的字段顺序由其派生；不重排配置模型、不改变 normalize 行为、默认值或配置键。连接角色沿现有 `inline_connection_input` 元数据，不新增 Qwen 特判。
- 前端继续接受 `1.2–1.14` 目录的原语义，旧目录未声明调试属性时不猜测隐藏。`1.15` 保持原设置、语言、参数、凭据与节点重跑能力。
- 扩展节点只需声明类别、调试属性和有序默认字段即可接入；同类别增加多个节点不增加顶级标签。已有设置、图和运行不因元数据更新被补写或迁移。
