# 可组合的节点配置与上下文

状态：**Implemented**（2026-11-09，Windows 本机验收）。本规格替换旧图中处理节点内嵌连接、模型、上下文及执行参数的契约。

## 范围与版本边界

- 处理节点负责调用适配器，可复用内容由独立节点经显式端口提供。LLM 翻译、Qwen Filetrans、Qwen Streaming 同轮拆分，不只改翻译。
- 用户已明确不保留旧图兼容：不迁移、不转换、不提供旧图只读模式，也不使用旧字段后备。处理节点拒绝旧的连接、模型和语言等内嵌字段。
- 新工作流文档、运行、批次及默认设置使用 `schema_version=2.0` 和新的存储命名空间；不加载旧图、旧运行或旧默认模板。旧文件不删除、不改写。项目、音频资源与 Transcript 的格式仍为 `1.0`，音频无需重新上传。
- 能力目录升为 `1.16`，前端按新声明构造节点和表单，拒绝旧目录。API 路径仍使用 `/api/v1`；路径版本不等于各文档的持久化版本。
- 不引入 Agent、数据库、独立 Worker、子图或可变长度端口，不恢复 Profile、环境变量密钥和旧 Provider。

## 节点职责

| 节点 | 职责 | 主要输出 |
| --- | --- | --- |
| 服务连接 | 协议、地址、可选地域、独立密钥引用 | 连接绑定 |
| 模型配置 | 连接绑定、自由模型名、显式请求参数 | 模型绑定 |
| 文本值 | 可多行编辑的普通文本 | `string` |
| JSON 值 | 有界 JSON 对象 | `json_object` |
| 文本拼接 | 按 left、right 顺序及分隔符连接 | `string` |
| JSON 合并 | 顶层键合并，显式选择冲突策略 | `json_object` |
| 翻译上下文 | 源语言、目标语言、要求、背景、术语表 | 翻译上下文 |
| 识别上下文 | 识别语言提示 | 识别上下文 |
| 翻译执行参数 | 总超时、分批、相邻片段、有限重试 | 翻译执行参数 |
| 识别执行参数 | 总超时 | 识别执行参数 |
| LLM 翻译 | 消费当前文本、模型、上下文、可选执行参数 | 当前译文的 Transcript |
| Qwen Filetrans / Streaming | 消费音频、模型、可选识别上下文及执行参数 | 识别 Transcript |

模型名称仍为自由配置，不建立永久模型白名单。连接的协议是已实现适配器的注册标识；同协议的新模型只需配置，新增协议则需要显式适配器和注册声明。

## 组合规则

- 一个输出可以连接多个消费者。同一模型、连接、上下文或执行参数均可在图内复用；共享只通过连线发生，不按相同地址或内容自动合并。
- 构造节点可以手填字段，也可从显式声明的参数端口取得值。接线时隐藏手填控件，但保留合法后备；执行时校验实际组合值。
- 字段声明 `input_port` 及 `input_type_id`，支持标量和 JSON 对象；字符串多行编辑由 `widget` 声明，前端不按节点名猜用途。
- 文本拼接首版为二元，默认分隔符为两个换行。多份文本用多个拼接节点连接，次序由端口明确，不依赖边 ID 或创建顺序。
- JSON 合并只合并顶层键；默认重复键报错，也可明确选择保留左值或右值。不会递归合并或静默截断；组合后的对象仍执行大小、深度及消费端校验。
- 翻译上下文中的要求、背景可以分别接文本拼接结果，术语表接 JSON 对象或合并结果；术语表要求字符串到字符串映射。业务词条如 `password → 密码` 合法，不按敏感词禁用普通 JSON。
- 翻译目标语言在执行前必须提供。源语言为空时，在每次调用中继承直接上游当前文本语言；第二个翻译节点使用第一个的译文及语言。
- 识别语言为空时逐音频继承源语言，不能在批次提交时用首份音频补齐全部上下文。首版识别上下文只表达现有协议支持的语言提示，不把翻译背景或术语当作未经支持的 ASR 参数发送。
- 请求参数在模型配置中声明，可从 JSON 节点输入，默认不发送附加字段。协议校验禁止覆盖核心输入、路由、认证、工具及响应结构；不同协议不兼容时在调用前明确拒绝。
- 执行参数包与模型请求参数分开；总超时属于前者。未接执行参数的处理节点使用对应参数模型的声明默认值，不补读全局设置。
- 音频仍为单源，批次仍在图外逐文件展开；节点及边各 64 个的现有限制不变。

## 凭据与冻结

- 密钥归服务连接节点所有，绑定项目、连接节点 ID 及凭据类型；处理节点不拥有密钥，也不能任意借用其他节点的引用。
- 多个处理节点通过同一连接的模型绑定显式共享不可变凭据版本。复制连接节点、粘贴及可移植导入导出清除引用和私有密码缓冲；全局默认 Key 只在新连接首次保存时物化为其独立版本。
- 连接及模型端口、checkpoint 只包含严格校验的公开描述与不透明凭据引用，不能包含真实 Key。恢复时校验项目、owner、协议及引用与冻结图一致；只在适配器调用边界解密。
- 保存仍使用只写 `credential_updates`、原子发布和稳定请求 ID；密码不进入草稿、撤销、本地存储、测量克隆、响应或日志。
- 普通运行、批次及重试使用自身冻结图和凭据版本；编辑连接、模型或全局默认值不改变已排队工作。

## 纯配置求值与重跑

- 注册声明区分 `configuration` 与 `processing`，并以 `can_start_without_inputs` 表达可无输入起步、但允许可选接线的构造节点；调度器不按内置节点类型分支。
- 同一配置求值路径用于普通运行、提交检查和节点重跑；需要音频元数据的值逐音频解析。
- 从处理节点重跑时，必要纯配置祖先重新物化，必要处理祖先仍须验证并复用 checkpoint。修改连接、Key 版本、模型、上下文或参数会影响递归指纹，不能误复用旧处理结果。
- 不因配置祖先变化强迫用户从连接根重跑所有分支；必要处理祖先失效仍要求前移起点，不自动追加付费调用。原运行及产物不改写。
- 预览和文本导出继续只读取直接上游的当前文本，不因模型、上下文或前驱类型变化切换到其他分支。片段 ID、原文、时间轴和说话人保留。

## 验收

- 新默认直通图、现有音频上传/清单、批次、输出命名、取消、编辑器和全局设置回归。
- 两个翻译节点共享模型/连接，使用独立上下文完成 `ja → en → zh`；背景、要求、合并术语实际出现在假平台请求中，预览/导出分别显示正确当前文本。
- 两种 Qwen 处理节点消费独立配置节点，真实协议假服务验证语言、模型、附加参数及超时；错误协议不发送网络请求。
- 多个消费者共享一个 Key；复制不继承 Key；跨项目/owner 的伪造引用拒绝；日志、数据响应、checkpoint 无明文 Key。
- 文本和 JSON 的多级组合、重复键策略、组合后超限、参数接线后备、非法对象和自定义模型。
- 修改纯配置后从处理节点重跑可成功；修改处理祖先依赖后从下游重跑明确拒绝；只重跑导出不新增模型请求。
- 新存储不读取旧图、旧运行、旧批次和旧默认模板，旧文件原字节不变；项目及音频资源继续可用。旧文档版本和旧节点内嵌字段明确拒绝。
- Windows 本机后端全量、Ruff、前端全量和构建、独立假平台与真实 Edge 验收。仅报告实际结果，不将未测平台或真实服务质量写成已验证。
