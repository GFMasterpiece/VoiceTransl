# 普通文本上下文与多输入拼接

> 历史里程碑：ASR 上下文已移除，LLM 改为节点内手填或从字段旁插口接线。服务分类、当前字段和版本以[服务分类与字段输入](service-families-field-inputs.md)为准；以下保留当时实现与验收记录。

状态：Implemented · 2026-11-10

## 目标与范围

上下文是普通字符串。移除专用“翻译上下文”“识别上下文”节点、数据类型和固定的语言/要求/术语字段。用户可直接连接文本值，或用多输入文本拼接组织源语言、目标语言、背景、要求、术语等内容，同一字符串可供多个消费者使用。

连接、模型、JSON 请求参数及执行参数仍分别维护。处理节点从明确的端口取得输入，不在通用运行器或前端按具体节点类型猜用途。普通文本字符串与包含时间轴的 Transcript/文本下载产物保持区别。

## 文本拼接

- 配置保存有序 `items=[{id,value},…]` 和 `separator`，允许 1–32 项；默认两项及双换行分隔符。
- 每项使用唯一稳定 ID，端口为 `text_<id>`；新增、删除或排序不改变其他项的 ID 和接线。
- 每项可以多行手填，或连入字符串覆盖；连接隐藏控件并保留手填后备，断线恢复。分隔符仍可手填或接线。
- 按列表顺序严格执行 `separator.join(values)`，不修剪文本、不忽略空项。输入及最终字符串均遵守 64 KiB UTF-8 上限；超限失败，不截断。
- 当前动态组仅支持字符串，`default_items` 从后端配置模型派生。后端 `dynamic_inputs` 声明驱动端口展开、表单、校验、参数覆盖、布局、可移植操作与缓存指纹；不能向全局端口表注册每个实例的动态 ID。
- 删除输入项与移除该端口的边为一次可撤销编辑；撤销恢复内容、ID、顺序和连线。排序不重连其他项，复制保留内部 slot ID，仅重映射节点 ID。

## 处理器上下文

### LLM 翻译

`context` 是必需的字符串输入，不能为空白。自由上下文原样提供给模型；应用不解析自然语言猜目标语言，也不再要求独立的源语言、目标语言、要求或词表字段。当前文本的已有语言可作为输入元数据，不替代用户上下文。

适配器保留固定的输出结构协议，模型返回 `{language,translations}`。语言为实际输出语言的非空代码；每批返回的片段 ID 必须准确覆盖对应输入，分批结果语言须一致，否则按有限重试规则失败，不能回退或猜测。连续翻译读取上一轮译文及其返回语言；原文、片段 ID、时间轴和 speaker 保留。预览、导出读取直接上游的当前文本。

### Qwen 识别

两种 Qwen 节点接受可选字符串 `context`。空值省略；非空值按官方协议包装为一条 `user/input_text` 消息：Filetrans 放在 `input.context`，Streaming 放在 `run-task.payload.input.context`。不发送虚构的 assistant 消息，不把自然语言转成协议参数。

官方每轮文本上限为 400 字符，本实现发送一条消息，超限在上传或握手前明确拒绝，不静默截断。音频语言继续取该份资源的声明，不从上下文推断；附加请求参数不能覆盖上下文、核心输入、路由或认证。Mock 只消费音频声明生成示例，无专用上下文节点。

协议依据：[Filetrans HTTP API](https://platform.qianwenai.com/docs/api-reference/speech-recognition/qwen-audio-asr-filetrans/http-api)、[Streaming 客户端事件](https://platform.qianwenai.com/docs/api-reference/speech-recognition/qwen-audio-asr-streaming/client-events)。

## 地域及字段契约

地域是可选人工标签，不决定服务路由。省略、`null` 和空串均可，不要求所有服务提供地域；界面明确标为可选。地址仍必须含合法协议，错误定位地址而不是误报地域或某个特定处理器。

能力字段通过 `nullable` 声明是否允许 `null`，独立于是否必需、默认值及运行时业务校验。Pydantic 可空类型的非空分支约束也必须发布。前端通用验证消费该声明，不能靠地域/凭据字段名称或角色绕过类型检查。

## 版本及持久化

- 能力目录升级为 `1.17`；图、运行、批次及服务端默认设置为 `3.0`，使用 `v3` 存储命名空间。仅接受新契约。
- 用户已明确丢弃旧图；不读取、迁移或转换旧图、运行、批次及模板，不提供只读旧图功能。旧文件留盘原样，项目、音频和 Transcript 资源仍为 `1.0`，无需重新上传。
- 凭据归属、不可变版本、显式连线共享、写入幂等、复制/导出剥离及排队冻结不变。私密输入不进入草稿、撤销或测量克隆。
- 普通字符串配置祖先支持重物化；顺序、分隔符、slot ID、手填后备和连线变化纳入指纹。只重跑导出不得产生额外外部请求；处理祖先依赖变化须拒绝错误复用。

## 验收

- 地域可空且长度约束保留；无协议地址明确报错，普通可空扩展字段也按声明验证。
- 三项以上拼接的手填、接线、排序、删除、撤销/重做、复制/剪切/粘贴和保存刷新正确；空项与 Unicode 大小限制无隐式改写。
- 两种 ASR 请求实际包含用户原文；401 字符在任何外部请求前拒绝，空上下文不发送。
- LLM 请求含完整自由上下文，语言只取有效模型响应；验证两次翻译接力、缺/错语言、分批语言不一致、ID 完整性、原文和时间轴。
- 节点重跑、批次排队冻结、凭据隔离/轮换、取消、超时和默认值继续有效；旧命名空间不读取且原字节不变。
- Windows 后端全量与 Ruff、前端全量与构建、隔离假服务与真实 Edge 验收。使用合成音频和假密钥，不调用付费服务；未实测系统不宣称已验证。
