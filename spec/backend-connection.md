# 浏览器后端连接设置

状态：Implemented（2026-11-09）。

## 目标与交互

- 主页连接状态可点击，打开后端地址弹窗；状态来自实际 `GET /api/v1/health`，区分检测中、已连接和未连接。
- 提供地址输入、测试连接、连接并保存、恢复默认。恢复默认只填写默认地址，取消不生效；不增加说明段落。
- 接受 HTTP(S) 服务根地址、带服务前缀的地址或以 `/api/v1` 结尾的完整 API 地址，以及同源绝对路径。服务地址自动追加 `/api/v1`，完整 API 地址不重复追加。
- 拒绝带认证信息、查询、片段、反斜杠和协议相对地址的输入。地址不包含 Qwen 服务配置或 API Key。
- 测试不修改当前地址；修改输入或关闭弹窗后，过期检测不能覆盖当前状态或触发保存。检测设置有界超时，失败保留原连接及输入。

## 保存与隔离

- 地址仅保存在当前浏览器；未设置时继续使用 `VITE_API_BASE_URL` 或 `/api/v1`，保留开发代理默认行为。
- 健康检测成功、浏览器存储成功后整页刷新应用。无法存储时显示错误，不切换服务；不在原页面热切换请求目标。
- 入口只在主页提供，与创建项目和全局设置弹窗互斥；项目写入及应用期间禁止切换。离开画布仍沿用已有草稿、上传和提交保护。
- 新页面从新后端读取项目、目录及全局设置，不保留另一后端的内存缓存、密码输入、上传队列或轮询会话。切换不取消旧服务上的后台任务。
- 未确认批次请求按实际 API origin、路径及项目隔离；自定义服务不得恢复旧部署未确认请求。旧未分域请求仅在默认部署读取并迁入新键。
- 上传、任务、批次、ZIP、预览和产物下载共用启动时 API 地址。后端返回的 `/api/v1/...` 资源路径映射到配置的 API 前缀；已有完整 HTTP(S) 资源 URL 保留原解析契约。

## 后端跨源支持

- 默认只向 HTTP(S) loopback 前端 origin（`localhost`、`127.0.0.1`、`[::1]`，可带端口）提供跨源读取授权。
- 其他前端 origin 由服务端 `app.cors_origins` 或 `VOICETRANSL_CORS_ORIGINS` 显式列出；禁止 `*`、`null`、含路径或认证信息的配置，不开放携带凭据的 CORS。
- 允许当前 REST 方法、JSON/文件上传和媒体 Range 请求；普通错误响应也遵循同一来源规则。
- 不改变持久化 schema、能力目录版本、节点云服务连接或密钥归属，不引入远程认证机制。

## 验收

- 单元测试验证地址规范化、无效地址、超时、迟回、存储失败、弹窗互斥、真实状态、资源前缀及未确认批次隔离。
- 后端测试验证精确 allowlist、loopback 边界、跨源健康、JSON/上传/Range 预检和错误响应；无关来源不获得读取授权，预检被拒绝。
- 使用两个独立临时数据目录的后端及真实浏览器验证默认代理、自定义跨源连接、刷新持久化、恢复默认、项目及全局设置隔离、上传与预览下载。
- 小屏、键盘关闭及中英文界面可用；不使用用户密钥、数据或付费模型。
