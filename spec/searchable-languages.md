# 可搜索语言候选

状态：**Implemented**（2026-11-09）。识别语言与音频源语言提供候选及搜索，保留自定义语言代码。

## 范围

- Mock ASR、Qwen Filetrans、Qwen Streaming 的识别语言字段，以及单份音频源语言、清单默认源语言和逐行源语言，共用后端候选源。
- 候选展示中文名、英文名、语言原名及代码，可按任一名称、代码或别名搜索；提交只保存选定的代码。
- 候选是常见语言的编辑便利，不是模型支持清单或永久白名单。列表之外的代码仍可显式输入，服务协议及实际模型决定是否接受。
- 云识别语言空值继续继承输入音频语言，源语言仍必填；Mock 识别保留默认 `ja` 及非空校验。已有代码、未知代码及历史图不自动改写或映射。

## 接口与目录

- `GET /api/v1/capabilities` 顶层增加 `languages: [{code,names:{"zh-CN",en},native_name,aliases:[]}]`，由后端独立语言目录统一维护。
- 能力目录 `workflow.schema_version` 为 `1.12`；字段增加 `suggestion_source: "languages" | null`，识别语言通过节点显式声明。字段仍为字符串，原默认值、验证和 `input_port` 不变。
- 前端按声明选择控件，不用字段名或节点类型猜测；上传也消费同一候选源，不另建前端语言名单或逐控件请求接口。
- 新目录严格检查候选及声明形状；旧目录缺元数据时沿用原字符串输入行为，不推断声明或伪造候选。能力查询失败沿现有错误路径处理。
- 只增展示元数据，持久化 schema 保持 `1.0`。候选、搜索词和显示名称不进入配置、运行快照或执行版本摘要。

## 交互

- 使用可搜索组合框。搜索词与已选代码分开；选候选或确认“使用自定义代码”才更新值，Escape 或失焦取消搜索，输入法组合期间 Enter 不提交。
- 未确认搜索不改变图和撤销记录；对应源语言上传/默认应用按钮临时禁止操作，避免将搜索文字或旧值误当新选择。选中或取消后恢复原条件。
- 支持方向键、Enter、Escape、Tab 及鼠标操作；焦点保留在输入框，候选层不触发节点拖动、框选或删除。
- 候选浮层不参与节点尺寸测量，避免被节点和表格裁切；跟随缩放、平移、滚动和窗口变化定位，并限制在视口内。
- 接线隐藏、禁用、保存/上传锁、弹窗、切项目与卸载时收起并清理监听；只收起浮层不改已选代码、图、私有密钥或原文件。
- 保持简洁，仅显示字段、候选与必要短状态，不增加说明段落。

## 验收

- 各语言字段支持中文/英文/原名/代码/别名搜索，候选选中仅写代码，自定义/未知/旧值保持原样。
- 输入法、键盘、取消搜索、语言切换、空识别语言及必填源语言正常；未选搜索不会上传或写成语言值。
- 候选来源单一，动态扩展字段声明可复用控件，普通字符串字段不被误判。坏目录明确失败。
- 参数接线隐藏与恢复、撤销重做、节点缩放和布局、焦点/浮层清理及密码缓冲保持正常；旧文件原字节与语义摘要不变。
- 后端全量/Ruff、前端全量/构建，以及 Windows 隔离浏览器的候选选择、上传语言和布局检查通过后完成；不调用付费模型。
