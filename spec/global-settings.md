# 全局设置与节点创建默认值

状态：**Implemented**（2026-11-09）。在项目主页提供设置面板，统一调整上传/工作流并发，以及新建 ASR 节点的默认字段和密钥。

## 范围和交互

- 主页提供“全局设置”按钮，使用现有弹窗和全局表单样式，分组展示通用设置与节点默认值。仅显示字段、控件、短状态和必要错误，不恢复说明段落。
- 通用项包括上传并发数和工作流执行并发数。上传并发缺省 3，范围 1–32；工作流并发沿用正整数限制。字段约束由后端发布，前端不重复维护限制。
- 节点自行声明可设置的创建默认字段。首批包括 Mock ASR 的语言、Qwen Filetrans 和 Streaming 的连接及处理配置；模型名仍为自由字符串，语言复用可搜索候选。凭据引用、项目资源和运行状态不能作为普通默认字段。
- API Key 使用密码输入，只写更新，留空保持，支持清除。保存失败保留输入以便重试，成功清空；关闭未保存面板需确认放弃，不把明文放入可序列化状态、本地存储或日志。

## 接口和持久化

- 能力目录升级为 `1.13`，表示可读取全局设置；沿用 `1.12` 的语言声明形状。持久化 schema 仍为 `1.0`，旧目录不请求或推断新的设置能力。
- `GET /api/v1/settings` 返回 `{schema_version,revision,global_fields,global,node_defaults}`。通用字段声明和节点字段均复用能力字段结构；`node_defaults` 按类型提供 `{label,fields,config,credential_configured,credential_version}`，版本令牌可空，绝不返回明文 Key。
- `PUT /api/v1/settings` 接受 `{schema_version,expected_revision,request_id,global,node_defaults,credential_updates}`。`node_defaults` 仅提交类型到配置的映射；只写密钥更新为 `{node_type,operation:set|clear,api_key?}`。
- 设置文件放在服务端数据目录，JSON 原子发布，revision 防止并发覆盖，request_id 支持丢失响应的幂等重试。同请求不能换内容；失败不发布新设置，不改变原 revision。
- 文件缺失时 revision 为 0，从现有启动配置取得并发初值及注册默认配置，不因 GET 创建文件。保存后的全局并发优先于该两项 YAML/env 初值；其他启动配置继续原路径。
- 文件存在但损坏、版本未知或配置不再可识别时明确报错，不能静默回退或覆盖。默认值验证沿用节点完整配置校验，不增加服务商支持名单。

## 创建默认值及凭据

- 仅通过“添加节点”创建的新节点深拷贝当前普通默认字段；读取已有图、历史、复制、粘贴及导入不自动重新应用默认值。运行和重试不读取全局默认值。
- 默认密钥在独立私有命名空间中加密保存，每次替换生成不可变版本，绑定节点类型及 Provider 类型。清除当前默认绑定不删除旧版本。
- 新节点在私有会话缓冲中捕获当时的密钥版本，保存工作流时通过只写 `credential_updates` 提交 `{node_id,operation:use_default,default_credential_version}`。服务端校验类型归属并物化项目/节点独享的不可变凭据；图、修订与运行只记录物化后的节点引用。
- 不透明默认版本不能写入图、普通撤销状态、导出或本地存储。默认密钥意图与撤销步骤的关联只在私有会话中维护，不记录明文；撤销重做不补读最新全局值，不向复用 ID、粘贴或导入节点泄漏意图。手填或清除显式覆盖该意图。
- 工作流保存的同请求重放保持原节点凭据，不能被“仅新增节点可使用默认”校验误拒绝。默认 Key 更新后，已创建但未保存的节点仍使用创建时捕获的版本。
- 本功能提供创建模板，不恢复旧 Profile、环境变量密钥备用或运行时共享连接。原节点独立连接与密钥、队列快照和原历史保持不变。

## 并发与上传

- 工作流并发使用稳定实例的可调许可器，与普通运行和批次共用。升高后唤醒等待者；调低不取消已运行任务，在后续许可和批次取项边界遵守新上限；等待取消不丢许可、不遗留旧等待队列。
- `/upload-policy` 增加 `upload_concurrency`。前端每次启动上传队列时捕获已加载策略值，控制同时传输的文件数；在主页保存设置后进入编辑器会加载新策略，不中断当前传输。其他客户端更改策略时，已打开编辑器使用缓存，重新进入后更新。旧策略缺少字段继续沿原行为。
- 上传和执行分别配置，不把上传完成当作运行，也不修改批次清单、独立运行、编号和失败重试语义。

## 验收

- 设置读取、修改、刷新和服务重启恢复；原子写失败、revision 冲突、响应丢失重试及坏文件保持原样。
- 后端声明扩展节点字段能复用默认表单；未知/非法字段明确拒绝；原图、快照与摘要不被默认设置更改。
- 两种 Qwen 默认配置及密钥分别设置，多个新节点物化独立凭据；默认旋转、类型混用、保存重放、手填覆盖、复制/导入及撤销重做边界。
- 密钥不出 GET、日志、图、导出或前端可序列化状态；保存失败不丢输入。
- 动态升降并发、普通运行与批次共享上限、等待取消；上传策略控制并发且不丢失败重传和浏览器 File。
- 中英文、语言候选、弹窗焦点/关闭保护、桌面及窄屏布局；后端全量/Ruff、前端全量/构建及隔离浏览器验收，不调用付费服务。
