# LLM API 翻译节点与当前文本

状态：Implemented（2026-11-09）。

## 范围

新增 `llm_translate`，归入“翻译”，以 `transcript → transcript` 接入工作流。首版直接请求兼容 Chat Completions 的 HTTP API，不引入自主 Agent、工具调用、浏览器检索、独立任务系统或本地模型。节点可串联、分支，沿用批次及节点级重跑。

每个实例独立设置服务地址、模型和密钥；不提供模型白名单，不恢复旧 Profile 或环境变量密钥路径。全局设置只提供新建模板，复制粘贴不携带密钥。运行、排队和重试继续冻结节点连接、凭据版本及配置。

## 上游当前文本

- 预览、导出和后续翻译只消费直接上游提供的当前文本，不根据节点类型、处理阶段或图中是否存在翻译节点猜测。
- 通用声明为 `Transcript.metadata.current_text={version:"1",field:"source_text"|"normalized_text"|"translated_text",language:"语言代码"}`。统一领域函数负责读取与校验，扩展节点也可使用。
- 无声明的旧转写沿用 `source_text` 和 `Transcript.language`；非法声明或指定字段无有效内容应明确失败，不回退原文。
- 翻译节点深拷贝输入，将结果写入 `translated_text` 并声明其为当前文本；保存当前目标语言，保留原始 `source_text`、片段 ID、顺序、时间轴、说话人及其他原文元数据。
- 第二个翻译节点使用第一个的译文；空源语言继承上游当前语言。第一轮结果仍保存在第一节点产物中，不覆盖历史，也不在单个片段上无限追加多轮字段。
- ASR 直接连接预览/输出显示原文；翻译后连接显示译文，不新增隐式回溯或原文/译文选择器。
- 持久化 schema 保持 `1.0`，能力目录保持 `1.15`；旧文件不迁移、不改写，旧产物保持原样。`text_output` 与 `text_preview` 的执行版本升为 `2`，避免沿用旧渲染语义的 checkpoint；当前文本声明须通过 typed checkpoint 和重跑传递。

## 节点配置

| 字段 | 默认及约束 |
| --- | --- |
| `base_url` / `model` | 空；用户填写兼容服务 API base 与自由模型名 |
| `timeout_seconds` | 120，1–3600；覆盖本节点全部分块、请求及等待 |
| `source_language` | 空，继承上游当前语言；可搜索语言候选及自定义代码 |
| `target_language` | 空，执行前必须提供；可搜索候选及自定义代码 |
| `instructions` | 空，最多 8192 字符，用户翻译要求 |
| `glossary` | 空 JSON 对象，字符串到字符串，不超过 16 KiB |
| `batch_size` | 20，1–100 |
| `max_batch_characters` | 6000，256–30000，约束每批正文及上下文字符预算 |
| `context_segments` | 2，0–10，提供有限相邻上下文 |
| `max_attempts` | 2，1–5，每批有限尝试 |
| `additional_parameters` | 空对象；仅显式值随请求发送，不得覆盖消息、认证、路由及改变协议的核心参数 |
| `credential_ref` | 隐藏，只写密钥物化为节点独享引用 |

允许未完成配置保存在草稿和默认模板。节点声明通用执行前校验：提交时，地址必须有效，未填写且未接参数的模型/目标语言被拒绝；参数线的实际值在执行合并后再次校验。失败不能发出模型请求。模型、源语言和目标语言可使用字符串参数线。

## 翻译与失败语义

- 请求 `POST <base_url>/chat/completions`；默认仅发送模型及消息，不主动发送 temperature、token 上限、JSON mode、流式开关等可选参数。
- 按顺序分批，提供有限前后上下文和术语表；上下文不作为本批待返回片段。字符预算不是 token 数，不自动推断模型窗口。
- LLM 只返回 JSON 中的片段 ID 和译文；检查精确 ID 集、重复/未知/缺失项、非空译文及结束状态，不允许模型重排、改时间或补造片段。完整 JSON 围栏可剥离，不从任意正文贪婪抽取结果。
- 超长单片段在首个请求前明确拒绝，不截断、不猜时间戳。无时间戳正文可翻译和预览、导出 TXT，字幕格式沿用时间戳校验。
- 仅对明确的限流、服务端错误及无效输出做有界重试；认证/配置失败不重试，连接中断或超时不自动重发可能已经受理的请求。所有等待均可取消并受总 deadline 约束。
- 任一分块失败或取消时不发布完整转写/下游结果；成功后原子写入新节点产物，不修改上游文件。取消回收请求与连接，不保证撤回远端已经处理的内容。
- 单次响应限制 4 MiB，累计译文按 UTF-8 限制 64 MiB；跨批超限停止后续请求、不重试、不发布部分结果。
- 不在错误、运行日志或传输调试日志中记录密钥、请求正文和原始模型响应。测试只使用合成文本、假密钥与本机假服务。

## 验收

- ASR→翻译→翻译的第二次请求确实使用第一次译文及其语言；原文、片段结构和源产物不变。
- 分支预览和 TXT/SRT/VTT/LRC 导出严格跟随各自上游，旧无声明转写仍显示原文；非法当前文本不能静默回退。
- 参数线、独立密钥、全局创建默认值、复制剥离、冻结排队/批次重试、checkpoint 复用和重跑保持原契约。
- 覆盖缺配置、坏 JSON、错 ID、截断、限流、认证失败、重试、超时、取消、超长片段和敏感日志，所有失败不发布假成功。
- 前后端全量测试、Ruff、生产构建及隔离假 API 的真实浏览器端到端验证通过；不宣称已验证真实模型质量或计费。

协议参考：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。只复用协议形状，不固定服务商或模型。

## 实际验收

- Windows 本机后端全量 878 passed、7 skipped，Ruff 检查及格式检查通过（120 文件）；前端 553 项测试及生产构建通过。
- 独立 Edge 与本机假 API 完成 7 组验收：动态节点发现与执行前校验、独立凭据及两轮语言/译文接力、原文/两轮译文三路预览与 SRT、输出节点重跑零新增云请求、无效译文阻断下游、取消实际 HTTP 断连、双文件批次及默认设置/English/390px 界面。
- ZIP 实际包含两份第二轮译文字幕，编号保留 00001/00002；原始运行文件不变，临时数据目录没有明文测试密钥。跨批累计输出上限及边界由适配器回归覆盖。
- 测试均使用合成音频、Mock 识别文本、假密钥和假翻译，不代表真实模型质量、配额、计费或 Linux 部署已验证。用户原有服务与数据未用于浏览器验收。
