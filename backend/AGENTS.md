# 后端会话工作边界

本目录的会话只负责 VoiceTransl 后端实现与后端测试，工作范围为 `backend/`。遵循仓库根目录 `AGENTS.md` 的架构、安全、Git 和文档规则。

- 不修改 `frontend/` 的代码或测试，也不替前端会话实现 UI。
- 如需前端配合（例如新增/改变 API、字段、错误语义、运行时能力或用户确认流程），向前端开发会话发送明确请求，写明接口方法/路径、请求响应字段、错误和验收条件，请前端会话完成其范围内的实现。
- 若依赖前端实现后端契约才能定稿，先提出契约建议及影响，不要通过修改前端代码解决。
- 只读查看前端以理解对接现状是允许的；不得把只读检查变成跨目录改动。
- 后端代码要求、测试命令和 Provider 契约以根目录规则及 `docs/` 对应专题文档为准。
